## 폴더별 용도

| 폴더 | 내용 | 언제 쓰나 |
|---|---|---|
| `ppt/` | PowerPoint 4종 + PDF 2종 | 발표·배포용. 기능마다 「움직이는 화면」 + 「정지 화면」 두 장씩 |
| `gif/` | 원본 화질 GIF (23개) | 문서 삽입, 사내 공유. 0.1~2.1MB |
| `gif-light/` | 용량 줄인 GIF (23개) | 첨부 용량 제한이 빡빡한 게시판. 전부 0.9MB 이하 |
| `mp4/` | 동영상 (19개) | PPT 삽입, 사내 영상 플랫폼 |
| `png/` | 단계별 낱장 이미지 (85장, 01~18) | 게시판 본문 사이사이에 끼워 넣을 때 |
| `strip/` | 세로로 이어붙인 안내 이미지 (20장, 01~18) | **GIF가 안 움직일 때의 대체본** |

## 게시판에 올릴 때 — 순서대로 시도해 보세요

1. **`gif/` 를 그대로 올려봅니다.** 업로드 후 글을 저장하고, 실제로 움직이는지 확인하세요.
2. 용량 제한에 걸리면 **`gif-light/`** 로 바꿔서 올립니다. 화질은 그대로 읽히고 용량만 절반 이하입니다.
3. 올라갔는데 **안 움직이면** — 게시판 에디터가 이미지를 재인코딩한 겁니다. 이때는 **`strip/` 의 세로 이미지 1장**으로 대체하세요. 단계·번호·설명이 이미 다 들어가 있어서 그 한 장만으로 안내가 됩니다.
4. 본문에 단계별로 나눠 쓰고 싶으면 **`png/`** 의 낱장을 문단 사이에 넣으면 됩니다.
5. 사내에 영상 플랫폼이 있으면 **`mp4/`** 를 올리고 게시판에는 링크만 거는 방법도 있습니다.

## PPT에서 GIF가 어떻게 동작하나

- 슬라이드쇼(**F5**)에서만 재생됩니다. 편집 화면에서는 첫 장면만 보이는 게 정상입니다.
- 전부 **무한 반복**으로 저장돼 있어서 슬라이드에 머무는 동안 계속 돕니다.
- **PDF로 저장하거나 인쇄하면 움직임은 남지 않습니다.** 그래서 기능마다 정지 화면 슬라이드를 한 장씩 같이 넣어뒀습니다.
- 더 매끄럽게 하고 싶으면 GIF 대신 `mp4/` 를 삽입하세요. PowerPoint에서 자동 실행·반복 재생을 직접 설정할 수 있고 용량도 더 작습니다.

## 09~17 만든 방식 (2026-09-19)

`_scripts/` 의 Playwright 스크립트로 찍고 ffmpeg 으로 변환했습니다. 화면이 바뀌면 **스크립트 재실행만으로 다시 만들 수 있습니다.**

| 단원 | 촬영 스크립트 | 뷰포트 |
|---|---|---|
| 09 | `rec-home-left.js` | 1920×1080 |
| 10 | `rec-home-right.js` | 1920×1080 |
| 11~16 | `rec-menus.js` (인자로 하나만 지정 가능) | 1440×900 |
| 17 | `rec-dict.js` | 1920×1080 |
| 18 | `rec-lnb.js` | 1920×1080 |

```bash
cd ../_scripts
node rec-menus.js calendar    # 12번만 다시 촬영
./build.sh 12_calendar        # gif / gif-light / mp4 다시 생성
./build.sh                    # 09~17 전부 다시 생성
```

**뷰포트가 단원마다 다른 이유**

- 09·10 — 홈 대시보드가 1440 폭에서는 캘린더와 히트맵이 잘립니다.
- 17 — 사전 관리 모달이 1440 폭에서 `신규 등록`·`닫기` 버튼까지 화면 밖으로 나갑니다.
- 11~16 — 1440 으로 충분하고, 기존 01~08 과 규격이 같아 매뉴얼 안에서 잘 맞습니다.

**알아둘 것**

- 09·10은 설명하지 않는 쪽 영역을 반투명 흰색으로 덮었습니다. 안 그러면 크롭 경계에서 카드가 반쯤 잘려 지저분합니다.
- 15(휴지통)는 `복구`·`영구삭제` 열이 1440 폭에서 가로로 잘려 있어, 표를 오른쪽으로 밀어서 보여줍니다.
- 16(이용 현황)은 차트가 `<canvas>` 라 수치를 목업할 수 없습니다. **0인 실제 화면 그대로** 찍고, 말풍선으로 "무엇이 표시되는지"만 설명합니다.
- 18은 `내 회의록` 을 **`미완성 회의록` 으로 바꾸고 폴더 아래로 옮겨서** 찍은 화면입니다 (`patch.js` 의 `applyLnbPatch`). 실제 사이트에는 아직 `미완성 회의록` 이 없습니다. 반영되면 `rec-lnb.js` 의 `applyLnbPatch` 호출 두 줄만 지우면 진짜 화면으로 다시 만들어집니다.
- 17은 실제로 `세미컨덕터 → 반도체` 를 등록한 화면입니다. 다시 촬영하면 **중복 등록**되니, 먼저 사전에서 해당 항목을 지우고 찍어야 합니다.
