## 6. ★ ValidateToken 이 500 일 때 — systemID 대소문자 고치기 (회사에서)

> 11-27: SSO 서버 `ValidateToken` 이 `{"status":500}` 을 줬다. 🔸 가장 의심되는 건 **요청 본문 키 이름 대소문자**.
> 자료마다 다르다: 명세 `systemID` / 11-09 샘플 `SystemID` / **11-16 Java 샘플 `systemId`**. 지금 서버는 `systemID` 로 보낸다.
> 고치는 곳은 **앱이 아니라 인증서버(auth-api)** 다. 앱은 `{ authzToken }` 만 보내므로 앱 쪽은 고칠 게 없다.

### 6-1. 먼저 볼 것 (서버 로그)
- `[SSO_AMTRAY] ValidateToken 응답 =>` 줄 — 지금은 `status`·`result`·`hasUserId` 만 찍힌다. **응답 본문 전체**(토큰 값 빼고)를 찍어 달라고 하면 원인이 바로 보일 수 있다(예: `message` 에 "systemId is null").
- `[SSO_AMTRAY] ValidateToken 호출 실패 =>` 줄이 나오면 그건 연결 자체 실패(주소·방화벽·인증서) — 대소문자 문제가 아니다.

### 6-2. 고칠 곳 — `backend/auth-api/src/services/commonService/ssoAmTray.js`
(집 사본: `docs/sso-amtray-java/backend-request/src/services/commonService/ssoAmTray.js` 46~50줄)

바꾸기 전:
```js
const { data } = await axios.post(
	url,
	{ systemID, authzToken },
	...
```

**1차 시도** — Java 샘플대로 `systemId`:
```js
	{ systemId: systemID, authzToken },
```

1차도 500 이면 **2차 시도** — 첫 글자 대문자:
```js
	{ SystemID: systemID, authzToken },
```

> 키를 둘 다 넣는 방법(`{ systemID, systemId: systemID, authzToken }`)도 있지만, SSO 서버가 모르는 키를 거절하면 오히려 실패할 수 있어 하나씩 바꿔 보는 쪽을 권한다.
> 바꾼 뒤 서버 재시작 → 앱에서 시스템 로그인 한 번 → 6-4 표로 판단.

### 6-3. 같이 볼 것 — 주소 대소문자 (`.env`)
- `AMTRAY_VALIDATE_URL` 개발 `https://samlamdev.skhynix.com/tray/api/ValidateToken`
- Java 샘플은 `.../tray/api/validateToken`(소문자 v). 주소가 틀리면 보통 404 → `호출 실패` 줄이 나와야 하므로 가능성은 낮지만, 키를 바꿔도 안 되면 이것도 바꿔 본다.
- `AMTRAY_SYSTEM_ID` 가 `AIMEETING` 인지(오타·공백)

### 6-4. 결과 보는 법 (서버 로그 `ValidateToken 응답 =>`)

| 응답 | 뜻 | 다음 |
|---|---|---|
| `status 500`, `result ""` | 그대로 — 키 이름이 아니거나 SSO 서버 쪽 문제 | 다음 시도 / 6-1 본문 전체 로그 → AM 담당자에게 문의 |
| `result "SYSTEMID_INVALID"` | **키는 맞았다.** 시스템 ID 값이나 등록 문제 | AM 담당자에게 AIMEETING 등록 확인 |
| `result "TOKEN_INVALID"` | **키는 맞았다.** 토큰이 만료·재사용됨 | 앱에서 다시 로그인(토큰은 매번 새로 받음) |
| `result "SUCCESS"`, `hasUserId true` | ✅ 성공 | 2장 3번부터 |
| `httpCode 403` (앱 로그) | 검증은 성공, 사번에 맞는 사용자가 없음 | 웹 SSO 로 한 번 로그인해 계정 만들기(인계문서 4-1) |

### 6-5. 고친 값 알려 주기
어느 키 이름에서 됐는지 적어 와 주면 집 사본(`backend-request`)·문서(`response-codes.md` 4-3)에도 반영한다.
