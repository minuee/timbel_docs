Audio Sync Capture Platform — 전체 시스템 개요

이 문서는 현재 프로젝트를 녹음 앱 + 세션/제어 서버 + 오디오 처리 엔진으로 재정의한 뒤, 실제 구현과 연구를 어떤 구조로 진행해야 하는지 한 장에서 이해할 수 있도록 만든 개요입니다.

1. 시스템 3층 구조

Capture Layer

모바일 녹음 앱

  • room create / join / ready / start
  • 연구 모드 규칙 강제
  • 녹음 시작 telemetry 기록
  • 파일 업로드

Flutter 앱 셸 + native recorder bridge

→
Control Plane

세션/제어 서버

  • room lifecycle
  • minimum_ready_participants
  • server-authoritative start
  • metadata persistence

여기서 start는 acoustic truth가 아니라 control prior

→
Processing Layer

오디오 처리 엔진

  • canonicalization
  • metadata prior narrowing
  • anchor detection
  • audio fine alignment / drift correction
  • mixdown + manifests

2. 왜 backend-only가 부족했나

문제

파일만 받는 구조의 한계

  • 누가 언제 눌렀는지 알기 어려움
  • 앱/기기/route 차이를 수집하지 못함
  • 연구용 ground truth를 만들기 어려움
  • 실험 규칙이 흔들림
해결

앱 기반 capture protocol

  • room 기반 세션 관리
  • ready/start rule 통제
  • telemetry 수집
  • 연구 모드 규칙 강제

3. End-to-End 시퀀스

1

Room 생성

방장이 room 생성, room code 공유

2

참가자 Join

device/app/os 정보와 함께 room 참가

3

Ready

mic route / processing flags 점검 후 Ready

4

Start

서버가 start_command_id와 issued_at 발급

5

Record

앱이 start received → record invoked → recording started 기록

6

Upload / Process

업로드 후 backend가 정렬/믹스/manifest 생성

핵심 규칙: server start는 control prior이고, 최종 정렬 진실값은 anchor + 오디오에서 얻습니다.

4. 연구 모드 기준

항목 연구 모드 이유
포맷 wav / pcm / 48kHz / mono 재현성 확보
마이크 경로 built_in_mic only route variability 제거
anchor mandatory 정량 검증용 기준점 확보
pause/resume disallowed session drift 해석 단순화
시작 규칙 host start + minimum_ready_participants 동일 세션 정의 명확화

5. 꼭 수집해야 하는 정보

필수 metadata

  • room_id
  • session_id
  • participant_id
  • device_id
  • recording_started_at
  • sample_rate_hz, channels, codec
  • mic_route
  • audio_processing_flags

연구 모드 telemetry

  • start_command_id
  • server_start_issued_at
  • start_command_received_at
  • client_record_invoked_at
  • local_monotonic_start_tick
  • anchor_type
  • anchor_expected_at

6. 테스트 층

Layer 1

Synthetic

ground truth가 있는 offset/drift benchmark

Layer 2

Controlled-device

실제 스마트폰 + 연구 규칙 + anchor

Layer 3

Field validation

실제 회의 + STT 품질 + listening review
