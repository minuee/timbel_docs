# 빌드 이력

새 버전을 만들 때마다 표 **맨 위에** 한 줄 추가한다 (최신이 위).
루트의 `VERSION` 파일도 같은 값으로 고쳐야 `build.sh` 가 그 태그로 빌드한다.

| 버전명 | 변동내용 | 변동일자 |
|---|---|---|
| 0.0.1 | 최초빌드 | 2026.09.21 |
| 0.0.2 | 비프음 개념 적용, 모니터링 로그 추가 | 2026.09.22 |
| 0.0.3 | 비프음 두가지(방장-기본, 전체) 구조 적용 | 2026.09.29 |
| 0.0.4 | 싱크음 3종(beep/voice/jingle) 선택, 방장 비프 2차 탐색, 종료 싱크음 드리프트 보정, 오토믹서, 진단 명령 sync-scan, 결과 파일 위치 로그 | 2026.10.22 |
| 0.0.5 | 파일 1개도 비프 기준 자르기(BEEP_MIN_TRACKS=1), 비프 못 찾으면 파일별 느슨한 기준·안내음성으로 재탐색, 안내음성 오검출 방지(순음 확인), 종료 비프 못 찾으면 안내음성으로 계산, 결과 음량 맞추기(구간별), Swagger Bearer 토큰 버튼 | 2026.10.23 |

| 0.0.7 | 하울링(울림)·STT 단어 반복 대응: 싱크음으로 맞춘 뒤 말소리 파형으로 다시 맞추기(ALIGN_REFINE, 기본 켜짐, 다른 장소 트랙은 그대로), 결과 음량 맞추기 기본 끔(MERGE_LEVEL=off) | 2026.11.06 |
| 0.0.8 | 하울링 대응 방향 변경: 폰 소리를 더하지 않고 순간마다 가장 가까운 폰 하나만 쓰기(AUTOMIX_MODE=select 기본, 0.0.7 방식은 share), 응답·로그에 폰별 들린 비율과 전환 횟수(merge_automix) | 2026.11.09 |
