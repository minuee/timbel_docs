## 폴더별 용도

| 폴더 | 내용 | 언제 쓰나 |
|---|---|---|
| `ppt/` | PowerPoint 2종 + PDF | 발표·배포용. 기능마다 「움직이는 화면」 + 「정지 화면」 두 장씩 |
| `gif/` | 원본 화질 GIF (9개) | 문서 삽입, 사내 공유. 0.1~1.9MB |
| `gif-light/` | 용량 줄인 GIF (9개) | 첨부 용량 제한이 빡빡한 게시판. 전부 0.9MB 이하 |
| `mp4/` | 동영상 (9개) | PPT 삽입, 사내 영상 플랫폼 |
| `png/` | 단계별 낱장 이미지 (39장) | 게시판 본문 사이사이에 끼워 넣을 때 |
| `strip/` | 세로로 이어붙인 안내 이미지 (8장) | **GIF가 안 움직일 때의 대체본** |

## 게시판에 올릴 때 — 순서대로 시도해 보세요

1. **`gif/` 를 그대로 올려봅니다.** 업로드 후 글을 저장하고, 실제로 움직이는지 확인하세요.
2. 용량 제한에 걸리면 **`gif-light/`** 로 바꿔서 올립니다. 화질은 그대로 읽히고 용량만 절반 이하입니다.
3. 올라갔는데 **안 움직이면** — 게시판 에디터가 이미지를 재인코딩한 겁니다. 이때는 **`strip/` 의 세로 이미지 1장**으로 대체하세요. 단계·번호·설명이 이미 다 들어가 있어서 그 한 장만으로 안내가 됩니다.
4. 본문에 단계별로 나눠 쓰고 싶으면 **`png/`** 의 낱장을 문단 사이에 넣으면 됩니다.
5. 사내에 영상 플랫폼이 있으면 **`mp4/`** 를 올리고 게시판에는 링크만 거는 방법도 있습니다.

## PPT에서 GIF가 어떻게 동작하나

- 슬라이드쇼(**F5**)에서만 재생됩니다. 편집 화면에서는 첫 장면만 보이는 게 정상입니다.
- 전부 **무한 반복**으로 저장돼 있어서 슬라이드에 머무는 동안 계속 돕니다.
- **PDF로 저장하거나 인쇄하면 움직임은 남지 않습니다.** 그래서 기능마다 정지 화면 슬라이드를 한 장씩 같이 넣어뒀습니다.
- 더 매끄럽게 하고 싶으면 GIF 대신 `mp4/` 를 삽입하세요. PowerPoint에서 자동 실행·반복 재생을 직접 설정할 수 있고 용량도 더 작습니다.
