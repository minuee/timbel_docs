## 2. ★ `.env` 의 `AMTRAY_DLL_INIT` 비우기

11-17 앱 로그(`amtray_token_code`)에 `"init": "201010"` 이 찍혔다 = 토큰 요청 앞에 Init 을 따로 불렀다.
회사 `.env` 에 예전 시험 때 넣은 **`AMTRAY_DLL_INIT=true` 가 남아 있어서**다(코드 기본값은 false).

```
AMTRAY_DLL_INIT=
```
- 이렇게 **값을 비운다**(줄은 남겨도 됨). 매뉴얼: "GetSystemToken 은 Init 을 포함" → 따로 부르지 않는 게 맞다.
- 11-17 결과로는 Init 을 해도 안 해도 502011 이라 **원인은 아니다**. 매뉴얼대로 맞춰 두는 것.
- 확인: 앱 로그 `amtray_token_code` 의 `init` 이 **`"skipped"`** 로 나오면 된다.
- ⚠️ `.env` 에 다른 AM-Tray 값(`AMTRAY_SID`·`AMTRAY_SSO_KEY` 등)이 **값이 든 채로** 남아 있으면 `app.config.json` 보다 먼저 쓰인다. 전부 비어 있는지 한 번 훑어볼 것.

## 4. ★ 알림(Window Message) 시험 — 스위치 두 가지로

### 왜
11-17: 앱 먼저 켜고 AM-Tray 웹 로그인 → 앱이 알림을 못 받음. 원인 후보 셋 (모두 🔸 추측)
1. 우리 시스템 미등록 → AM-Tray 가 아예 안 보냄 (502011 과 같은 원인)
2. AM-Tray 가 우리 창을 찾는 방법을 모름 (제목? 클래스? — 6장 담당자 질문)
3. **DLL 을 창이 없는 작업 프로세스에서 불러서** — AM-Tray 가 "Init 을 부른 프로세스의 창"으로 보내는 방식이면 못 받는다

이번 시험은 **3번**을 가린다.

### 로그에서 볼 것
| 로그 | 뜻 |
|---|---|
| `amtray_window_hook_installed` (`env: 31001`) | 앱이 알림 받을 준비 됨 (늘 나옴) |
| `amtray_dll_in_main_process` | **스위치 `main` 이 먹었다** (main 일 때만, 처음 DLL 호출 때 한 번) |
| **`amtray_login_hash`** | **★ 로그인 알림을 받았다** |
| `amtray_copydata_ignored` | 알림은 왔는데 환경값(wParam)이 다르다 → `wParam` 값 적기 |
| `amtray_logout_message` | 로그아웃 알림을 받았다 |
| 위 셋 다 없음 | 알림이 우리 창에 안 왔다 |

### 순서 — 시험 ① 스위치 `""` (지금 방식)
1. `app.config.json` 의 `"AMTRAY_DLL_PROCESS": ""` 그대로
2. **AM-Tray 로그아웃** (트레이 아이콘에서)
3. `npm start` → 로그인 화면에서 **[시스템 로그인]** (ver2 면 자동) → 502011 안내가 뜨면 닫기만 하고 **앱은 켜 둔다**
4. AM-Tray 트레이 아이콘으로 **웹 로그인**
5. 1분쯤 기다리며 위 표의 로그가 나오는지 본다
6. **AM-Tray 로그아웃** 도 한 번 → `amtray_logout_message` 가 나오는지

### 순서 — 시험 ② 스위치 `"main"`
1. 앱 끄고 `app.config.json` 에서 `"AMTRAY_DLL_PROCESS": "main"`
2. 시험 ① 의 2~6 그대로. 3번 뒤에 **`amtray_dll_in_main_process`** 가 찍혔는지 먼저 확인
3. **끝나면 반드시 `""` 로 되돌린다** (빌드 전에도)

### 결과 보는 법
| ① `""` | ② `main` | 뜻 |
|---|---|---|
| 안 옴 | **옴** | 🔸 3번이 원인 → "Init 만 본체에서" 같은 방식으로 정식 반영 검토 |
| 안 옴 | 안 옴 | 1번 또는 2번 → 담당자 답(등록·창 찾는 방법)을 기다림 |
| 옴 | 옴 | 11-17 이후 뭔가 바뀜(등록이 됐을 수도) → GetSystemToken 도 다시 해 볼 것 |

> ⚠️ `main` 일 때 주의: DLL 이 죽으면 **앱도 같이 꺼진다**. DLL 호출 동안 화면이 잠깐 멈출 수 있다. 녹음은 하지 말 것.
