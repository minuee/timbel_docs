## 새 기능을 추가하는 절차 (Claude용)

`_build/` 폴더에 제작 스크립트 전체가 들어 있습니다. 순서는:

1. `frames_lib.py` → `SOURCES2`에 새 GIF 등록
2. `steps.py` → `UNITS`에 제목·소개·단계 추가
   - 단계는 `(프레임번호, 설명)` 또는 `(프레임번호, 설명, 자를영역)`
   - `STEP_CROP` = 단원 전체 확대, `BOARD_COLS` = 정지화면 열 수 지정
3. `build_media2.py` → GIF 원본/경량 생성
4. `build_stills.py` → 단계별 PNG + 세로 스트립
5. `guide.py` → `SECTIONS`에 단원 배치
6. `build_guide.py` → PPT 2종 생성 (보드는 JPG로 변환해서 20MB 이하 유지)

주의: PPT가 20MB를 넘으면 폴더에 저장이 안 됩니다. `gif-mid/`(용량 중간)와 JPG 보드를 쓰면 19MB대로 맞춰집니다.

## 설계상 정해둔 것들

- 단원 순서는 파일명 순이 아니라 **업무 흐름 순**
- 설명이 가리키는 UI가 화면에 보여야 함 → 함부로 잘라내지 않기 (20번에서 한 번 실수함)
- 세로로 긴 화면은 정지화면을 가로 여러 칸으로 배치
- 게시판 대응: `gif/` → 안 되면 `gif-light/` → 그래도 안 되면 `strip/` 세로 이미지
