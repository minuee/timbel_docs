## 〈준비 중〉 단원을 채우는 방법

4개 단원(06, 07, 22, 23)은 **제목 + 들어갈 내용 목록 + 점선 자리**만 있는 상태입니다.

1. 해당 기능을 GIF로 녹화합니다
2. PowerPoint에서 그 슬라이드를 열고, 오른쪽 점선 상자를 지운 뒤 GIF를 넣습니다
3. 왼쪽의 「준비 중」 배지를 지우고, 목록을 단계 설명으로 바꿉니다

GIF를 주시면 제가 다른 단원과 똑같은 형식(움직이는 화면 1장 + 정지 화면 1장)으로 만들어 넣어드릴 수도 있습니다.

## 알아두실 점 — 「내 회의록」 메뉴 제거

새 버전에서 「내 회의록」이 빠졌는데, **18번을 제외한 GIF는 모두 제거 전에 녹화**된 것이라 왼쪽 메뉴에 아직 보입니다. 기능 설명 자체에는 지장이 없습니다.

다만 **12번 「회의록을 폴더로 옮기기」**는 폴더 이동 창의 선택지에 「내 회의록」이 나와서 실제 화면과 다릅니다. 여유 되실 때 그 단원만 다시 녹화해 주시면 교체하겠습니다.
