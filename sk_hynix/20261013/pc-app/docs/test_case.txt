1. 앱 실행, 종료
2. 오디오 시스템 초기화
   1) 디바이스 몰고 로드 확인(좌측 상단)
   2) 버전 확인(상단 가운데)
   3) 디스크 용량 확인(우측 상단)
3. 디바이스 선택 및 테스트
   1) 마이크, 녹음 모드 선택 후 테스트 버튼 및 테스트 시작 눌러서 레벨 확인
   2) 재사용(reuse) 확인: 테스트 시작 시 `reuse=true`이면 UI 초기화/레벨미터 재전송 생략, 버튼 상태만 갱신되는지 확인
4. 녹음
   녹음 시간 선택 후 녹음 시작(1초 이상 녹음할 경우에만 파일 저장)
   1) start -> stop : 파일 저장 확인 ( 마이크만, 시스템만, 마이크 + 시스템), 녹음 시간과 재생시간 확인
   2) start -> pause -> stop : 파일 저장 확인, 녹음 시간과 재생시간 확인
   3) start -> pause -> resume -> stop : 파일 저장 확인, 녹음 시간과 재생시간 확인
   4) 3분마다 파일 저장하므로 선택한 녹음 시간에 맞게 파일 저장되어 있는지 확인(예, 9분일 경우 3개 저장)
   5) 녹음 중에 녹음 선택한 마이크를 제거 : 현재까지 녹음한 데이터 저장된 파일 확인
   6) 시스템 사운드 변경(이어폰 -> 스피커) : 저장된 파일 재생하여 시스템 변경후 녹음되었는지 확인
   7) app.js에 encryption_enabled를 true로 설정한 후 빌드하여 테스트(git에는 true). 저장된 파일을 aes256_decrypt.py로 복호화한 후 정상 재생 확인.
   8) AES 테스트 : 시스템 사운드를 스피커로 출력하면서 마이크 녹음 진행. 에코 있는지 확인.
   9) 디스크 용량 확인 : 디스크를 500MB 정도로 채운 후 녹음 시작, 10MB 파일을 복사 하면서 상태 확인. 50MB 미만일 경우 녹음 정지 되는지 확인.    
   10) 무음 감지 : 미디어를 재생하지 않거나 뮤트 , 마이크 뮤트 상태에서 녹음 진행, 시스템 로그에서 7초 이벤트와 30초 이벤트 확인
   11) 저장된 파일의 이름과 확장자 확인(sessionId_{n}.pcm, 예> abc-123_0.pcm, abc-123_1.pcm)
   12) 시스템에 선택된 마이크가 없을 때 동작 확인(테스트, 녹음 시작, 녹음중)
       - 선택된 마이크가 없으면 레코딩 시작할 수 없어야 하고, 녹음중이면 멈춰야 한다.   

6. 마이크 폴백 금지 관련
  1) 레벨미터 on 상태에서 선택 마이크 제거 → mic bar가 멈추고 `mic_state: unavailable` 수신 확인 (다른 마이크로 전환 금지)
  2) 선택 마이크 제거 상태에서 start_test/start 시도 → `NO_MIC_DEVICE` 에러로 거부 확인 (다른 마이크로 전환 금지)
  3) 선택 마이크 재연결(DEVICE_STATE_ACTIVE) 후 start_test/start → 정상 동작 및 mic bar 재개 확인
  4) HandleReinitAudio 경로: reqMicId/sessionMicId/selectedMicId 모두 비활성/없음일 때 기본 캡처 장치로 붙지 않고 `NO_MIC_DEVICE` 거부 확인

5. 레벨미터 확인
  1) 테스트 모드 후 레벨미터 계속 동작하는지 확인
  2) 테스트 종료 후 확인
  3) 녹음 시작 -> pause : 녹음 멈춰야함. 이 상태에서 저장하면 파일 재생시간이 pause된 시간과 동일. 
  4) 녹음 시작 -> pause -> resume : paus된 녹음 시간이 이어서 증가해야함. 
  5) 녹음 시작 -> pause -> resume -> 녹음 종료 후 확인 : stop 했을 때 녹음 시간과 동일해야함.
  6) 테스트 종료 후 자동 재시작 디바운스/백오프 확인(1s→2s→4s, 중복 재시도 없음)
  7) 녹음 시작 -> pause -> 선택된 마이크 제거 : 녹음 stop 되어야 하고, stop 했을 때 녹음 시간과 동일해야함.
  8) 녹음 시작 -> pause -> 선택된 마이크 제거 -> start : 시작되지 않아야함. 마이크 레벨 동작하지 않아야함.
  9) 녹음 시작 -> pause -> 선택된 마이크 제거 -> 선택된 마이크 연결 -> start : 시작해야함. 마이크레벨 동작해야함. stop 했을 때 녹음 시간과 동일해야함.
