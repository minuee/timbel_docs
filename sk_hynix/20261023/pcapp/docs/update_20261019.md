## ① 동영상 소리가 나오는데 파형이 안 움직이고 30초 무음 경고가 뜸 (녹음 자체는 정상)

### 원인
파형과 무음 경고 모두 **소리 크기(RMS)가 0.02(약 -34dB)보다 작으면 무음**으로 봤다.
0.02 는 원래 **마이크용** 기준이다(마이크엔 주변 잡음이 늘 깔려 있어 그걸 걸러야 함).
시스템 소리는 재생이 없으면 완전한 0 이라 잡음이 없는데도 같은 기준을 썼다.
그래서 동영상을 작은 볼륨으로 틀면:

| | 예전 기준 | 결과 |
|---|---|---|
| 파형 | 시스템 소리 < 0.02 → 막대 0 | 파형 안 움직임 |
| 무음 경고 | 최종 녹음본(시스템 × 0.7) < 0.02 → 무음 | 7초·30초 경고 |
| 녹음 파일 | 기준 없음 | **소리 그대로 저장 → STT 정상** |

### 조치
| | 지금 |
|---|---|
| 파형 | 시스템 소리는 **0.003(약 -50dB)** 이상이면 막대가 보임. 마이크는 0.02 그대로 |
| 무음 경고 ("회의 소리만" 모드) | 시스템 소리 기준 0.003 으로 판정 → 소리가 나오면 경고 안 뜸, **정말 아무것도 재생하지 않을 때만** 뜸 |
| 무음 경고 ("내 목소리 + 회의 소리", "내 목소리만") | 바꾸지 않음(0.02). 마이크 잡음이 섞이기 때문 |

- 0.003 은 추정값이다. 맞지 않으면 아래 "헬퍼 로그"의 RMS 값을 보내 주면 맞춘다
- Mac 헬퍼는 바꾸지 않았다(Windows 만)

## ② 다국어 (한국어 / English / 日本語 / 简体中文) — 옵션

### 켜고 끄기
`src/config/app.config.json` (개발 실행은 `.env` 가 우선)
```json
"MULTI_LANG_ENABLED": false
```
| 값 | 동작 |
|---|---|
| `false` (기본, 지금 값) | 설정 메뉴에 "언어"가 **안 보이고** 항상 한국어. 고객 화면은 지금과 같다 |
| `true` | **로그인·마이크 테스트 화면 맨 아래** 언어 선택 상자(🌐), **녹음 화면 설정 메뉴 → 언어** ▶ 한국어 / English / 日本語 / 简体中文 |

- 고른 언어는 `AppData\Roaming\timbloRecApp\language.json` 에 남아 다음 실행에도 쓴다. `false` 로 돌리면 이 파일이 있어도 한국어
- 언어를 고르면 **열린 창이 바로 바뀐다**(재시작 없음). 로그인·마이크 테스트·업로드 리스트·AI 요약·업데이트 화면, 시스템 알림 모두
- 로그인·마이크 테스트 화면에는 녹음이 없어 언제든 바꿀 수 있다. 녹음 화면에서는 **녹음 중(일시정지·오류로 멈춰 업로드/삭제 선택 전 포함)에는 막는다** — "녹음 중에는 언어를 변경할 수 없습니다." (장치 변경·로그아웃과 같음)
- 로그: `language_clicked`(lang, from, blocked, screen: login / mic_test — 녹음 화면은 screen 없음)

### 헬퍼 로그 보는 법
헬퍼 로그에 녹음 시작 후 5초마다 아래 줄이 찍힌다(소리가 한 번 감지되면 `Sound detected - silence detection disabled permanently` 가 찍히고 그 뒤로는 안 찍힘 — 정상). "회의 소리만" 모드면 `threshold` 가 `0.002100`(= 0.003 × 0.7) 으로 나와야 새 헬퍼다.
```
RMS level: 0.0xxxxx, threshold: 0.002100, isSilent: false
```
동영상이 나오는데도 `isSilent: true` 면 그 `RMS level` 값을 알려 줄 것 → 기준을 그 값에 맞춘다.
