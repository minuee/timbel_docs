## 2. 싱크음 3종

음원: `newDocs/assets/sync_sounds/` — **파일을 그대로 재생**해 주세요.

| `syncSound` | 시작 | 종료 |
|---|---|---|
| `beep` (지금 쓰는 것) | `1_beep3.wav` (3연타 비프) | `1_beep3.wav` (같은 파일) |
| `voice` | `2_voice.wav` "음성녹음을 시작합니다" | `2_voice_end.wav` **"녹음을 종료합니다"** |

- 시작·종료에 같은 비프/징글을 써도 됩니다. 서버가 위치(파일 앞 10초 / 끝 15초)로 구분합니다.
- 미디어 볼륨으로 충분히 크게 재생해 주세요.

## 3. 시작 싱크음

```
녹음 시작 ──(약 3초)──▶ 싱크음 ──────────────── 회의 ────────
```

- **녹음 시작 후 약 3초.** 정확할 필요는 없습니다. 서버는 앞 0~10초 안에서 찾습니다.
- 조건은 하나: 울리는 순간 **모든 폰이 이미 녹음 중**일 것 (녹음 시작 지연이 최대 2.2초).
- 지금처럼 **방장 폰만** 울리면 됩니다.

### 안내 음성을 같이 쓸 때 (`beep` / `jingle`)

```
녹음 시작 ─▶ "음성녹음을 시작합니다" ─▶ 끝나면 바로 비프(징글) ──── 회의 ────
                                          ↑ 서버가 여기 끝에서 앞을 잘라냄
```

- 순서: **안내 음성 → 싱크음.** 서버가 싱크음 끝에서 앞을 잘라내서 안내 음성도 결과에서 빠집니다.
- 반대로(싱크음 → 안내 음성) 하면 안내 음성이 결과에 남아 STT 에 "음성녹음을 시작합니다" 가 찍힙니다.
- master-api 에는 **비프(징글)** 값을 전달합니다.

## 4. 종료 싱크음 (신규) — 녹음 시계 오차 보정용

### 왜 필요한가

폰마다 녹음 시계가 조금씩 다릅니다. 1시간이면 폰끼리 0.1~0.4초 벌어져서,
시작은 맞춰도 **뒤로 갈수록 같은 말이 겹쳐 울립니다.** 시작과 종료에 같은 소리가 있으면
서버가 그 간격을 재서 폰별 오차를 맞춥니다.

### 동작

```
종료 버튼 ─▶ 바로 종료 싱크음 ─▶ (5초) ─▶ 실제 녹음 종료 ─▶ 업로드
              ↑ 서버가 여기부터 뒤를 잘라냄
```

- 종료 버튼을 누르면 **바로** 종료 싱크음을 울리고, **5초 뒤** 실제로 녹음을 멈춰 업로드를 진행합니다.
- 그 5초 동안 **모든 폰이 계속 녹음 중**이어야 합니다 (종료 싱크음이 모든 파일에 담겨야 함).
- 시작과 마찬가지로 **방장 폰만** 울리면 됩니다.
- 안내 음성을 같이 쓴다면 순서는 시작과 **반대**: **싱크음 → "녹음을 종료합니다"**.
  서버가 종료 싱크음부터 뒤를 잘라내므로 그 뒤 안내 음성은 결과에서 빠집니다.
  (`voice` 는 "녹음을 종료합니다" 가 곧 싱크음이므로 그것만 울리면 됩니다.)
- 종료 싱크음이 없는 녹음도 지금처럼 병합됩니다 (보정만 안 됨). 단계적으로 적용해도 됩니다.

## 5. master-api 에 전달할 값

| 앱 동작 | `syncSound` |
|---|---|
| 비프만 / 안내 음성 → 비프 | `beep` |
| 안내 음성만 | `voice` |
| 징글만 / 안내 음성 → 징글 | `jingle` |

방장만 울리는 동안은 `beepSource: "leader"` 도 함께 전달해 주세요.

## 6. 녹음 설정 (권장, 05 문서 4번 유지)

```dart
const config = RecordConfig(
  ...
  echoCancel: false,
  noiseSuppress: false,
  autoGain: false,
);
```

노이즈억제가 켜져 있으면 비프를 "잡음"으로 학습해 2·3번째 비프를 깎는 경우가 있습니다.
서버에 이를 보완하는 2차 탐색을 넣었지만, 끄는 쪽이 가장 확실합니다.

## 7. 나중에 `all` (전원이 각자 울림) 로 바꿀 때만

모든 폰이 각자 울리게 바꾸면, 폰끼리 재생 시각 차이가 그대로 정렬 오차가 됩니다.
그때는 각 폰의 녹음 시작이 아니라 **pub/sub 신호를 받은 시점 기준**으로 울려 주세요.
**지금(방장만 울림)은 해당 없습니다.**
