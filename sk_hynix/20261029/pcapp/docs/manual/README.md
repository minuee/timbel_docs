# PC 녹음 앱(SKHynix AI 회의록) 사용 안내

> 작성일: 2026-10-29 · 대상: 프로젝트 관리자 (기능 확인 및 피드백용)
> 기준: 2026-10-29 개발 소스 · 화면: 실제 앱 화면을 캡처했으며, 사번·이름·장치 이름·템플릿·회의명은 **예시 값**입니다.

PC 녹음 앱은 회의를 녹음해 AI 회의록 서버로 올리는 프로그램입니다. 올린 녹음은 서버에서 음성 인식과 요약을 거쳐 **AI 회의록(웹)** 에서 확인합니다.
아래는 현재 개발된 기능과 앞으로 적용할 기능을 정리한 안내입니다. 화면·문구·흐름에 의견을 주시면 반영하겠습니다.

```
설치 → 로그인 → 녹음 준비(마이크 테스트) → 녹음 → 종료·AI 요약 준비 → 업로드 → 웹에서 확인
```

## 1. 설치와 첫 실행

**설치 (Windows)**

1. 배포받은 `timbloRecApp Setup <버전>.exe` 를 실행합니다.
2. 설치 마법사에서 **설치 위치를 고를 수 있습니다** (기본 위치 그대로 두어도 됩니다).
3. 설치가 끝나면 바탕화면·시작 메뉴에 **SKHynixRecApp** 바로가기가 생깁니다.

> 서명 인증서가 없어 Windows SmartScreen 이나 백신 경고가 뜰 수 있습니다. [추가 정보] → [실행]을 누르면 설치됩니다.
> 설치 마법사 화면 캡처는 Windows PC 에서 따로 추가할 예정입니다.

**첫 실행**

- 앱을 실행하면 로그인 화면이 나타납니다. 로그인 상태가 아니면 항상 이 화면부터 시작합니다.
- 앱은 **한 번에 하나만** 실행됩니다. 이미 실행 중이면 기존 창이 앞으로 나옵니다.
- 화면 오른쪽 아래 작업 표시줄 트레이에 아이콘이 생깁니다 (Open / Quit).

![](img/01-1_first-launch.png)

## 2. 로그인

![로그인](gif/02_login.gif)

로그인 방법은 3가지이고, 관리자 설정으로 각각 켜고 끌 수 있습니다 ([부록 A](#부록-a-관리자-설정)).

| 방법 | 설명 | 상태 |
|---|---|---|
| ① 사번·비밀번호 | 앱에서 바로 입력 | 사용 가능 (현재 서버가 비밀번호를 검증하지 않아 운영에서는 끌 예정) |
| ② MyAccess 로그인 | 브라우저에서 사내 계정으로 로그인 → 앱으로 자동 복귀 | 사용 가능 |
| ③ 시스템 로그인 | PC(Windows) 로그인 정보를 SSO 엔진에서 받아 **입력 없이** 로그인 | **화면만 준비** — SSO 엔진 연동 자료를 받으면 적용 |

![](img/02-1_login-methods.png)

**① 사번·비밀번호**

1. 사번과 비밀번호를 입력합니다.
2. 필요하면 **[사번 저장]**(다음에 사번을 채워 둠), **[로그인 유지]**(앱을 다시 켜도 로그인 상태 유지)를 체크합니다.
3. **[로그인]** 을 누릅니다.

![](img/02-2_login-empno.png)

**② MyAccess 로그인**

1. **[MyAccess 로그인]** 을 누르면 PC 기본 브라우저에 MyAccess 로그인 화면이 열립니다.
2. 브라우저에서 로그인을 마치면 브라우저가 앱을 호출하고, 앱이 **자동으로 다음 화면**으로 넘어갑니다.
   (브라우저에서 "앱 열기" 확인이 뜨면 [열기]를 누릅니다.)

![](img/02-3_login-myaccess.png)

**③ 시스템 로그인 (적용 예정)**

- 사내 SSO 엔진(트레이 에이전트)이 가진 Windows 로그인 정보로 로그인하는 방식입니다. 사용자는 버튼만 누르면 됩니다.
- 현재는 버튼만 있고, 누르면 "시스템 로그인은 준비 중입니다." 가 나옵니다.

![](img/02-4_login-system.png)

**로그인 완료**

- 로그인되면 녹음 준비(마이크 테스트) 화면으로 넘어가고, 창 제목에 이름이 표시됩니다.

![](img/02-5_login-done.png)

**약관 미동의 안내**

- AI 회의록 약관에 동의하지 않은 사용자는 로그인 직후 안내 팝업이 뜨고 로그아웃됩니다.
- 링크(AI 회의록 시스템)를 누르면 브라우저가 열립니다. PC 에서 약관에 동의한 뒤 다시 로그인합니다.
- **이전에 동의한 사용자도 재동의가 필요합니다.**
- [로그아웃]: 팝업을 닫고 로그인 화면에 남음 / [앱 종료]: 앱을 끔

![](img/02-6_terms-notice.png)

## 3. 녹음 준비 (마이크 테스트)

![녹음 준비](gif/03_ready.gif)

| 항목 | 설명 |
|---|---|
| 녹음 대상 | 무엇을 녹음할지 선택 ([4장](#4-녹음-대상-3가지)) |
| 마이크 | 사용할 마이크 선택. **파란 막대** 가 내 목소리 크기 |
| 시스템 사운드 | **노란 막대** 가 PC 에서 나오는 소리(화상회의 상대방) 크기 |
| 출력 장치 | 회의 소리가 나오는 스피커 선택 (Windows 만) |

- 말을 해 보고 막대가 움직이는지 확인합니다. 움직이지 않으면 장치 연결·음소거를 확인하세요.
- 마이크를 빼거나 꽂으면 장치 목록이 자동으로 바뀝니다.

![](img/03-1_mic-test.png)

- **?** 아이콘에 마우스를 올리면 설명이 나옵니다.

![](img/03-2_help-tooltip.png)

**녹음 전 확인 → 녹음 시작**

1. 안내 문구를 확인합니다. (참석자 녹음 동의, 인식률, **최대 3시간**, 저장 공간)
2. **[위 내용을 확인했습니다.]** 를 체크하면 빨간 녹음 버튼이 켜집니다. 체크하지 않으면 녹음을 시작할 수 없습니다.
3. 녹음 버튼을 누르면 녹음 화면으로 넘어가며 바로 녹음이 시작됩니다.

![](img/03-3_agree-start.png)

## 4. 녹음 대상 3가지

![녹음 대상 3가지](gif/04_capture-modes.gif)

| 녹음 대상 | 녹음되는 소리 | 알맞은 회의 |
|---|---|---|
| **내 목소리 + 회의 소리** (기본) | 마이크 + PC 에서 나오는 소리 | 대면 + 온라인 참석자가 섞인 회의 |
| **내 목소리만** | 마이크만 | 회의실 대면 회의 |
| **회의 소리만 (상대방)** | PC 에서 나오는 소리만 (내 목소리 제외) | 여러 참석자가 각자 녹음해 나중에 하나로 합칠 때 |

- 고른 값은 저장되어 다음 실행 때도 유지됩니다.
- **회의 소리만** 을 고르면 화면에 주의 문구가 나옵니다. 화상회의 앱의 소리가 이 PC 스피커로 나오고 있어야 하며, 마이크는 시간 맞춤용으로만 씁니다.

| 내 목소리 + 회의 소리 | 내 목소리만 | 회의 소리만 |
|---|---|---|
| ![](img/04-1_mode-mic-plus-system.png) | ![](img/04-2_mode-mic-only.png) | ![](img/04-3_mode-system-only.png) |

## 5. 녹음 중

![녹음 중](gif/05_recording.gif)

| 화면 요소 | 설명 |
|---|---|
| 진행 시간 | 빨간 점이 깜빡이면 녹음 중 |
| 남은 시간 | 최대 3시간. 시간이 줄면 막대 색이 바뀜. 3시간이 되면 자동 종료 후 업로드 여부를 물음 |
| 마이크·스피커 아이콘 | 누르면 각각 음소거 / 해제 |
| 파형 | 소리가 들어오면 움직임. 일시정지하면 회색 |
| 업로드 리스트 아이콘 | 오른쪽 위. [6장](#6-녹음-종료와-업로드) 참고 |
| 핀 아이콘 | 항상 위 켜기 / 끄기 |

- 녹음을 시작하면 **부서장에게 녹음 시작 안내 메일**이 발송됩니다 (관리자 설정).
- 녹음 중에도 창을 최소화하고 다른 프로그램을 쓸 수 있습니다.

![](img/05-1_recording.png)

**일시정지 / 재개** — 가운데 버튼을 누르면 일시정지, 다시 누르면 이어서 녹음합니다.

![](img/05-2_pause.png)

**음성 감지 알림** — 소리가 들어오지 않으면 안내 문구가 빨갛게 바뀝니다. 30초 이상 계속되고 창이 최소화되어 있으면 Windows 알림도 띄웁니다.

![](img/05-3_silence.png)

**빠른 버튼** — 항상 위·음소거는 아이콘으로 바로 켜고 끕니다. (같은 기능이 [설정 메뉴](#7-설정-메뉴)에도 있습니다.)

![](img/05-4_quick-buttons.png)

**녹음 취소** — [녹음 취소] → 확인을 누르면 녹음 파일을 **삭제**합니다. 삭제한 파일은 복구할 수 없습니다.

![](img/05-5_cancel.png)

**녹음 중 문제가 생기면** (안내 팝업으로 알려 줍니다)

| 상황 | 앱 동작 |
|---|---|
| 마이크 연결이 끊김 | 녹음을 자동 종료하고 안내. 지금까지 녹음한 파일은 업로드 가능 |
| 저장 공간 부족 | 500MB 미만이면 경고, 계속 부족하면 약 3분 뒤 자동 종료 (녹음된 부분은 저장) |
| 최대 3시간 도달 | 자동 종료 후 "업로드할까요?" (취소하면 삭제) |
| 녹음 중 앱 종료 | "녹음을 종료하고 업로드할까요?" — 업로드 또는 삭제 선택 |

## 6. 녹음 종료와 업로드

![종료와 업로드](gif/06_upload.gif)

1. **[녹음 종료]** 를 누르고 "파일을 업로드 할까요?" 에서 **[확인]** 을 누릅니다.

   ![](img/06-1_complete.png)

2. **AI 요약 준비하기** 창에서 항목을 고르고 **[AI요약 시작]** 을 누릅니다.

   | 항목 | 설명 |
   |---|---|
   | 제목 (선택) | 비워 두면 녹음 일시로 이름이 정해짐 (예: `A.Biz_p_rec_20261029_100000`) |
   | 요약 언어 * | 한국어 / 영어 / 일본어 / 중국어 |
   | 발화자 수 * | 1~2명 / 3~6명 / 7~10명 / 11명 이상 |
   | 템플릿 * | 서버에 등록된 요약 양식 (서버에서 받아 옴, 못 받으면 "기본형") |

   ![](img/06-2_summarize.png)

3. 업로드가 진행됩니다. 진행률·전송 속도·남은 시간이 보입니다. **완료될 때까지 앱을 끄지 마세요.**

   ![](img/06-3_uploading.png)

4. 업로드가 끝나면 안내가 나옵니다. 결과(음성 인식·요약)는 **AI 회의록 웹** 에서 확인합니다. 녹음 버튼을 누르면 바로 다음 녹음을 시작할 수 있습니다.

   ![](img/06-4_upload-done.png)

**업로드 리스트**

- 녹음 화면 오른쪽 위 아이콘으로 엽니다.
- 업로드 중인 파일과 **업로드에 실패한 파일** 이 보입니다. 실패한 녹음은 PC 에 남아 있으므로 **[재시도]** 로 다시 올립니다.
- 필요 없는 파일은 휴지통 아이콘으로 삭제합니다 (확인 후 삭제).

![](img/06-5_upload-list.png)

## 7. 설정 메뉴

![설정 메뉴](gif/07_settings.gif)

녹음 화면 왼쪽 위 **톱니바퀴** 를 누릅니다.

| 메뉴 | 설명 |
|---|---|
| 항상 위 | 창을 다른 창 위에 고정 (켜기 / 끄기) |
| 음소거 | 마이크와 회의 소리를 한 번에 음소거 / 해제 |
| 언어 | 화면 언어 변경 — 한국어 / English / 日本語 / 简体中文 |
| 장치 변경 | 마이크 테스트 화면으로 돌아가 장치를 다시 고름 (다시 로그인하지 않음) |
| 로그아웃 | 로그인 화면으로. 업로드 리스트의 파일은 그대로 남음 |
| 버전 정보 | 앱 버전, 헬퍼(녹음 엔진) 버전 |
| 앱 종료 | 앱을 끔 |

![](img/07-1_menu.png)

| 항상 위 | 음소거 | 언어 |
|---|---|---|
| ![](img/07-2_always-on-top.png) | ![](img/07-3_mute.png) | ![](img/07-4_language.png) |

- **녹음 중에는** 언어 변경·장치 변경·로그아웃을 막고 안내합니다. 녹음을 종료(업로드 또는 취소)한 뒤 다시 시도합니다. 업로드 중에도 로그아웃은 막습니다.

![](img/07-5_busy.png)

- 로그아웃은 확인 후 진행됩니다.

![](img/07-6_logout.png)

## 8. 다국어 (4개 언어)

- 화면 언어는 **한국어 · English · 日本語 · 简体中文** 4개를 지원합니다.
- 바꾸는 곳: 로그인·마이크 테스트 화면 아래 언어 선택 상자, 녹음 화면의 설정 메뉴 → 언어
- 고른 언어는 저장되어 다음 실행 때도 유지되고, 열려 있는 모든 창에 바로 적용됩니다.
- 화면 언어와 별개로 **요약 언어** 는 업로드할 때 고릅니다 ([6장](#6-녹음-종료와-업로드)).

아래는 녹음 전 확인 화면을 4개 언어로 본 예시입니다.

## 9. 자동 업데이트

![자동 업데이트](gif/09_update.gif)

- 앱을 켤 때 한 번 새 버전을 확인합니다 (Windows 설치본만).
- 새 버전이 있으면 업데이트 화면이 나오고 **자동으로** 내려받습니다. 이 화면에는 닫기 버튼이 없습니다 (강제 업데이트).
- 내려받기가 끝나면 설치하고 앱이 **자동으로 다시 실행** 됩니다. Windows 관리자 권한 확인 창이 뜨면 [예]를 누릅니다.
- 실패하면 잠시 안내 후 지금 버전으로 계속 쓰고, **다음 실행 때 다시 시도** 합니다.
- 녹음 중에는 끼어들지 않고 다음 실행으로 미룹니다.

## 부록 A. 관리자 설정

설치본의 설정 파일 `src/config/app.config.json` 에서 바꿉니다. 바꾼 뒤 앱을 다시 빌드·배포합니다.
값은 `true`/`false` 를 따옴표 없이 씁니다.

**로그인**

| 설정 | 현재 값 | 설명 |
|---|---|---|
| `EMPNO_LOGIN_ENABLED` | `true` | ① 사번·비밀번호 로그인 화면 표시. 서버가 비밀번호를 검증하지 않으므로 **운영은 `false` 권장** |
| `SYSTEM_LOGIN_ENABLED` | `true` | ③ [시스템 로그인] 버튼 표시. SSO 엔진 연동 전이라 지금은 "준비 중" 안내만 |
| `SSO_LOGIN_URL` | 개발 주소 | ② MyAccess 로그인 페이지 주소 (버튼은 항상 표시) |
| `SESSION_PERSIST_ENABLED` | `false` | [로그인 유지] 체크박스 표시. 체크하면 로그인 정보를 PC 에 암호화해 저장 |
| `MANUAL_LOGIN_ENABLED` | `true` | 테스트용 로그인(토큰 직접 입력) 표시. **운영은 `false`** |
| `TERMS_CHECK_ENABLED` | `true` | 로그인할 때 약관 동의 여부 확인 |
| `TERMS_AGREE_URL` | `https://aimeeting.skhynix.com/` | 약관 안내 팝업의 링크 |

**녹음·업로드**

| 설정 | 현재 값 | 설명 |
|---|---|---|
| `ALERT_ON_RECORDING_START` | `true` | 녹음 시작 시 부서장에게 안내 메일 |
| `RECORDING_FILE_PREFIX` | `A.Biz_p_rec_` | 제목을 비웠을 때 녹음 이름 앞부분 |
| `HMP_BASE_URL`, `DEFAULT_API_BASE_URL`, `MOBILE_SERVER_URL` | 모바일 서버 주소 | 로그인·업로드·메일 서버 |

**기타**

| 설정 | 현재 값 | 설명 |
|---|---|---|
| `MULTI_LANG_ENABLED` | `true` | 언어 선택 표시. `false` 면 한국어만 |
| `UPDATE_ENABLED` / `UPDATE_SERVER_URL` | `true` / 빈 값 | 자동 업데이트. **주소가 비어 있으면 꺼짐** |
| `LOG_SERVER_ENABLED` / `LOG_SERVER_URL` | `true` / 로그 서버 주소 | 앱 동작 로그를 서버로 전송 (장애 확인용) |
| `APP_DISPLAY_NAME` | `SKHynixRecApp` | 트레이 아이콘 이름 |

**운영 배포 전 확인**

- [ ] `MANUAL_LOGIN_ENABLED` → `false`
- [ ] `EMPNO_LOGIN_ENABLED` → 비밀번호 검증이 없으면 `false`
- [ ] `SYSTEM_LOGIN_ENABLED` → SSO 엔진 연동 전이면 `false` (버튼을 숨김)
- [ ] `SSO_LOGIN_URL` → 운영 MyAccess 주소
- [ ] `UPDATE_SERVER_URL` → 업데이트 파일을 올린 서버 주소

## 부록 C. 화면 자료 다시 만들기

화면이 바뀌면 스크립트를 다시 실행해 `img/`, `gif/` 를 한 번에 새로 만듭니다 (개발 PC 에서만).

- 스크립트: `docs/manual/_scripts/` — `scenes.js`(장면 목록), `lib.js`(촬영·합성), `mock.js`(앱 API 흉내)
- 앱 화면(HTML)을 Electron 없이 Chromium 으로 띄우고, 서버·오디오 장치 대신 예시 값을 넣어 찍습니다.
- 필요한 것: Node.js, `playwright-core` + Chromium, `ffmpeg`

```bash
cd docs/manual/_scripts
npm i playwright-core            # 처음 한 번 (이 폴더에 node_modules 생성, git 에는 올리지 않음)
npx playwright install chromium  # 처음 한 번
node scenes.js                   # 전체
node scenes.js 05 06             # 5·6장만
```
