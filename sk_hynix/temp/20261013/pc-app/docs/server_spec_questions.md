# PC 녹음앱 ↔ 서버 연동 확인 요청서

> **작성 목적**: PC 녹음앱(timbloRecApp)에 **업로드 옵션 UI(요약 언어 4종 / 요약 템플릿 3종)** 와 **2단계 업로드**를 추가하기에 앞서, 서버 API 스펙을 확정하기 위한 확인 요청 문서입니다.
>
> **작성일**: 2026-08-31
> **작성자**: 노성남
> **근거**: PC 앱(`recording-pc-app`) 및 모바일 앱(Flutter, `timblo-mobile-flutter`) 소스 코드 대조 분석
>
> 각 질문에 **답변란**을 비워두었습니다. 회신 시 해당 칸에 기입해 주시면 됩니다.

---

## 0. 배경 — 두 앱은 이미 같은 백엔드를 씁니다

분석 결과 PC 앱과 모바일 앱은 **동일한 업로드 엔드포인트·동일한 암호화 방식·동일한 오디오 포맷**을 사용하고 있습니다.

| 항목 | PC 앱 | 모바일 앱 |
|---|---|---|
| 녹음 업로드 | `POST /api/contents/upload/encryption/files` | 동일 |
| 암호화 | AES-256-CBC (고정 key/IV) | 동일 (C++ 헬퍼 주석에 "Dart 코드와 동일한 방식") |
| 오디오 | 16kHz / mono / PCM16 세그먼트 | 동일 |
| 최대 녹음 | 3시간 | 3시간 |

따라서 **신규 API 개발보다는 "PC가 아직 안 쓰고 있는 기존 스펙"을 맞추는 작업**이 대부분일 것으로 예상합니다.

**다만 아래 두 가지는 모바일 소스에도 존재하지 않아 신규 스펙 확인이 필요합니다.**
- 요약 언어 4종 (모바일은 현재 한국어/영어 2종만 노출)
- 2단계 업로드 (모바일은 단일 요청. 후속 LLM 호출 코드 없음)

**배경 — 현재 PC와 모바일의 동작이 다릅니다.**
