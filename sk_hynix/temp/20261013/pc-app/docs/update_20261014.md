## ① `npm run build` — GitHub 다운로드 막힘

자세한 내용은 `docs/build-offline/README.md`. 요약하면 이렇다.

1. 위 `package.json` 교체
2. `electron-builder-Cache.zip` 을 풀어 `Cache` 폴더째 `%LOCALAPPDATA%\electron-builder\` 아래에 넣는다
   → `%LOCALAPPDATA%\electron-builder\Cache\nsis\nsis-3.0.4.1\...` 이 되어야 함
3. `npm run build` → 로그에 `downloading url=https://github.com/...` 가 없으면 성공

## ② 로그 서버 — 사용자 동작(Info) 로그

- 모든 사용자 동작 로그에는 **`category: "user_action"`** 이 붙는다. Dozzle 에서 `user_action` 으로 검색하면 사용자 동작만 시간순으로 보인다
- 사번(`empno`)·디바이스 ID 는 전에 했던 대로 모든 로그에 자동으로 붙는다
- 이벤트 이름은 `message` 필드에 있다

| 화면 | message | 함께 남는 값 |
|---|---|---|
| 앱 | `app_started` | appVersion, platform, arch, osVersion |
| 앱 | `app_quit` | |
| 로그인 | `login_attempt` | method(`sso`/`empno`/`manual`), empno(사번·테스트 로그인) |
| 로그인 | `login_success` | method, empno |
| 로그인 | `login_failed` | method, reason, httpCode, serverMessage |
| 로그인 | `logout` | reason(`session_expired`) |
| 마이크 테스트 | `mic_test_opened` | |
| 마이크 테스트 | `mic_selected` | micName |
| 마이크 테스트 | `capture_mode_changed` | captureMode |
| 마이크 테스트 | `render_device_changed` | renderName |
| 마이크 테스트 | `notice_agreed` | checked |
| 마이크 테스트 | `recording_screen_opened` | micName, captureMode (녹음 시작 버튼) |
| 녹음 | `recording_started` | captureMode |
| 녹음 | `recording_start_clicked` | (종료 후 다시 녹음) |
| 녹음 | `recording_paused` / `recording_resumed` | sessionId, elapsedMs |
| 녹음 | `recording_cancel_clicked` / `recording_complete_clicked` | sessionId, elapsedMs, afterError |
| 녹음 | `recording_stopped` | sessionId, elapsedMs, stopType |
| 녹음 | `recording_stopped_by_device` / `_by_disk` / `_by_max_duration` | sessionId, elapsedMs |
| 녹음 | `mute_toggled` | target(`mic`/`system`/`both`), muted |
| 녹음 | `view_mode_changed` | mode(`memo`/`player`) |

- 팝업 `popupType` 읽는 법: `cancel` 확인 = 녹음 삭제, `complete` 확인 = 업로드 진행, `upload-progress` 확인 = 업로드 재시도(실패 후),

- 함께 고친 것: 렌더러에서 보낸 로그에 `message` 값이 들어 있으면 이벤트 이름이 덮어써지던 문제(메인 쪽은 어제 고쳤고 렌더러 쪽이 남아 있었다)

## ③ "녹음 전 확인해주세요" 펼치면 녹음 시작 버튼이 찌그러짐

- 원인: 화면이 `flex` + 높이 100% 라서 공간이 모자라면 버튼이 줄어들었다. 줄어든 버튼 위치로 창 높이를 계산하니 창이 커지지 않았다
- 수정: 요소가 줄어들지 않게 하고, 펼치면 **창 위치는 그대로 두고 아래로만** 늘어난다. 접으면 다시 줄어든다
- 화면 아래 끝(작업 표시줄 위)까지 키워도 모자라면 거기까지만 키우고 **세로 스크롤**이 생긴다

## ⑥ 업로드 팝업 개편 + 녹음 화면 정리 (제목·템플릿)

### 업로드 API (`docs/content-title.md`) 대비
| 필드 | 전 | 후 |
|---|---|---|
| `files`, `deviceId`, `fileName`, `totalNum`, `lang`, `attendeeNum` | 보냄 | 그대로 |
| `title` | **안 보냄** (녹음 화면 제목은 앱 DB 에만 있었다) | 팝업에서 입력한 제목. 비면 안 보냄 |
| `templateId` | 안 보냄 | 고른 템플릿의 `code`. "기본형"(code 없음)이면 안 보냄 → 서버가 `DEF-BASIC` |
| `manual` (메모·태그) | 보냄 | **제거** (메모·태그 기능 삭제, 서버 문서에도 없음) |

- 업로드 리스트에서 **재시도**해도 같은 제목·템플릿으로 간다 (앱 DB `summaries` 에 저장)

### 업로드 팝업 "AI 요약 준비하기" (560×500)
- 위에서부터: 제목 입력(선택) → 왼쪽 **요약 언어**(한국어/영어, 중국어 제거) + **발화자수**(1~2 / 3~6 / 7~10 / 11명 이상 → 0~3, "전체 대화" 제거) | 오른쪽 **템플릿 선택**
- 기본 선택: 한국어, 1~2명, 첫 번째 템플릿
- 버튼: 닫기 / **AI요약 시작**. "저장 전 확인해 주세요" 안내 문구 제거
- 템플릿 설명 칸은 넣지 않음 (웹용 화면에만 있음)

### 템플릿 목록 — `GET {MOBILE_SERVER_URL}/api/template?type=normal` (토큰 붙임)
- 로그인 직후 한 번 받고, 업로드 팝업을 열 때마다 다시 받는다. 팝업은 저장해 둔 목록을 먼저 보여주고, 새로 받으면 바꿔 그린다
- 마지막으로 받은 목록은 `%APPDATA%\timbloRecApp\templates.json` 에 남는다 → 서버가 안 될 때도 그 목록
- 한 번도 못 받았으면 "기본형" 하나만 (templateId 안 보냄)
- **★ 회사에서 확인**: 응답 모양이 다르면 `src/main/services/apiEndpoints.js` 의 `templates` 만 고친다
  ```js
  list: 'data',     // 응답 안에서 배열 위치. 응답 자체가 배열이면 ''
  codeKey: 'code',  // 업로드 때 templateId 로 보낼 필드
  nameKey: 'name',  // 화면에 보일 필드
  ```
  목록이 "기본형" 하나만 나오면 로그에서 `templates_empty`(모양 불일치) / `api_failed`(서버 오류) 를 찾는다

### 녹음 화면 (360×320 고정)
- 제목·메모·태그 입력, 메모/플레이어 모드 전환(버튼·설정 메뉴) 제거
- 그 자리에 **웨이브**: 녹음 중 파란 막대가 오른쪽에서 흘러 들어오고, **일시정지하면 멈추고 회색**. 음소거한 쪽 소리는 반영 안 함

- 설정 메뉴 "버전 정보" 에 헬퍼 버전 표시 (위 ⑤ 참고)
