## ① 요약 언어에 일본어·중국어 추가

업로드 창(요약 언어 선택)에 2개 추가. 괄호 안은 업로드 API 에 보내는 `lang` 값.

| 화면(한국어) | 보내는 값 |
|---|---|
| 한국어 | `ko` (기존) |
| 영어 | `en` (기존) |
| 일본어 | `ja` **새로** |
| 중국어 | `zh` **새로** |

- 다국어 표기: ko `일본어`/`중국어`, en `Japanese`/`Chinese`, ja `日本語`/`中国語`, zh-CN `日语`/`中文`
- 배치: `한국어 영어` / `일본어 중국어` 2줄 (한 줄씩 4개면 발화자수 영역과 함께 창 높이를 넘을 수 있음)
- 업로드 로직(`summarizeWindow.js` → `lang` 그대로 전달)과 DB(`summaries.lang` TEXT)는 **수정 없음**

## ② `timblo-App-OS` 헤더 자동 적용

지금은 `app.config.json` 의 `"APP_OS": "AOS"` 고정값이 나간다. 실행 환경으로 자동 결정하게 바꾼다.

| `process.platform` | 보내는 값 |
|---|---|
| `win32` (윈도우) | `AOS-WINDOWS` |
| `darwin` (맥) | `IOS-MAC` |
| 그 외 | `AOS-ETC` |

- 게이트웨이 406 검사는 "AOS/IOS **포함**" 여부라 세 값 모두 통과한다.
- `.env` 나 `app.config.json` 에 `APP_OS` 를 직접 적으면 그 값이 우선(지금처럼 강제로 바꿀 수 있게 유지). 그래서 `app.config.json` 의 `"APP_OS": "AOS"` 는 지운다.
- 로그 서버로 보내는 `appOs` 값도 같은 값으로 바뀐다.

> 회사 `app.config.json` 이 집 것과 다르면 통째로 바꾸지 말고 **`"APP_OS": "AOS",` 한 줄만 삭제**할 것.
