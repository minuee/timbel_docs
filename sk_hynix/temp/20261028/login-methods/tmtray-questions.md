# TmTray 연동 방식 확인 요청

PC 녹음 앱(SKHynix AI 회의록)을 **TmTray 방식(2번)** 으로 로그인하도록 연동하려고 합니다.
연동 매뉴얼을 공유해 주시면 가장 좋고, 어려우시면 아래 항목에 답을 주시면 그에 맞춰 개발하겠습니다.

> 녹음 앱은 Windows용 데스크톱 앱(Electron)입니다. C/C++/C# 앱과 같은 방식으로 DLL·실행 파일·로컬 통신 등을 모두 사용할 수 있습니다.

---

## 1. 연동 방식 (해당하는 것에 표시)

TmTray에서 로그인 정보를 받아오는 방식이 아래 중 무엇인지 알려주세요. 여러 개면 모두 표시해 주세요.

| 번호 | 방식 | 이런 형태입니다 | 알려주실 내용 |
|---|---|---|---|
| ☐ 1 | **C/C++ DLL 함수 호출** | `xxx.dll` + 헤더(`.h`), `GetToken()` 같은 함수 | DLL·헤더 파일, 함수 이름·인자·반환값, 호출 순서(초기화→조회→해제) |
| ☐ 2 | **.NET(C#) DLL** | C# 프로젝트에 참조로 추가하는 DLL | DLL 파일, 클래스·메서드 이름, 필요한 .NET 버전 |
| ☐ 3 | **COM / ActiveX 객체** | `CreateObject("xxx.yyy")`, ProgID·CLSID | ProgID, 메서드 이름, 등록(regsvr32) 필요 여부 |
| ☐ 4 | **실행 파일 호출** | `xxx.exe /get` 실행 후 출력·파일로 결과 받기 | 실행 파일 경로, 인자, 결과 형식 |
| ☐ 5 | **로컬 HTTP/WebSocket** | `http://127.0.0.1:포트/...` | 포트, URL, 요청·응답 형식 |
| ☐ 6 | **로컬 소켓 / Named Pipe** | TCP 포트 또는 `\\.\pipe\xxx` | 포트·파이프 이름, 메시지 형식 |
| ☐ 7 | **Windows 메시지** | TmTray 창에 `WM_COPYDATA` 등으로 요청 | 창 클래스·제목, 메시지 번호, 데이터 형식 |
| ☐ 8 | **공유 메모리** | 이름 있는 공유 메모리(Memory-Mapped File) | 이름, 데이터 구조, 동기화 방법 |
| ☐ 9 | **레지스트리** | `HKCU\Software\...` 값 읽기 | 키 경로, 값 이름, 암호화 여부·복호화 방법 |
| ☐ 10 | **파일** | 특정 경로의 ini·텍스트 파일 읽기 | 파일 경로, 형식, 암호화 여부·복호화 방법 |
| ☐ 11 | **TmTray가 앱을 실행하며 전달** | TmTray 메뉴에서 앱 실행 → 실행 인자로 토큰 전달 | 실행 방식, 인자 형식, 앱 등록 방법 |
| ☐ 12 | **Windows 통합 인증 (TmTray 없이)** | SSO 서버가 Kerberos/NTLM(Windows 로그인)을 직접 지원 | 인증 URL, 지원 여부 |
| ☐ 13 | 기타 | | 방식 설명 |
