## 2. 작업 설명

- 실제 앱 화면(`login.html`, `index.html`)을 가짜 서버로 띄워 찍었다. 사번 `12345678`, 이름 `홍길동`은 예시 값이다.
- 다국어 선택 상자와 테스트 로그인(토큰 직접 입력)은 화면에 나오지 않게 했다.
- `사번 저장`/`로그인 유지` 체크박스는 보이게 찍었다. 실제 앱은 `SESSION_PERSIST_ENABLED`가 false라 `로그인 유지`가 아직 안 보인다.
- 방식 2의 브라우저 화면은 `myaccess.example.com`으로 표시한 예시 화면이다. 실제 MyAccess 화면은 회사에서 캡쳐해 문의할 때 쓴다.

## 회사에서 확인할 것

| 무엇 | 어떻게 | 결과에 따라 |
|---|---|---|
| 큐브 메신저 자동 로그인 방식 | 큐브에서 **로그아웃** → 큐브 다시 실행 | 로그인 화면이 나오면 저장된 정보로 자동 로그인(우리 앱의 로그인 유지와 같음). 바로 들어가면 윈도우 로그인이나 SSO 에이전트 연동 → 고객사에 문의 |
| 큐브 설정에 "자동 로그인" 체크가 있는지 | 큐브 환경설정 | 있으면 저장 방식일 가능성이 높음 |
| 작업표시줄 트레이에 SSO/보안 에이전트가 있는지 | 트레이 아이콘 확인, 이름 메모 | 있으면 MyAccess 에이전트 연동 가이드를 요청 |
| 실제 MyAccess 로그인 화면 캡쳐 | 앱 [MyAccess 로그인] → 브라우저 화면 캡쳐 | 게시판 글에 예시 화면 대신, 또는 함께 첨부 |
| 게시판 글 작성 | `docs/login-methods/README.md` 내용과 GIF·이미지 첨부 | 고객사 답변(지원 방식, 연동 문서)을 다음 세션에 가져오기 |
