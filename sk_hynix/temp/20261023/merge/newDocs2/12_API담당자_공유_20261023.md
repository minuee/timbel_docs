## 2. 요청 — 그대로 (다시 확인)

```json
"options": {
  "align": "none",
  "beepSource": "leader",
  "syncSound": "beep"
}
```

- `beepSource: "leader"` — 지금처럼 **방장만** 비프를 울리면 명시해 주세요 (안 보내면 `all`, 앞부분이 0.3초 더 잘림).
- `syncSound: "beep"` — 앱이 안내 음성 → 3연타 비프를 울리므로 `beep`. 안내 음성은 비프 앞이라 같이 잘린다.
- `automix` 는 보내지 않아도 된다 (기본 켜짐).

## 3. 응답 — 추가된 필드

```json
"alignment": {
  "mode": "beep",
  "syncSound": "beep",
  "automix": true,
  "level": "dynamic",
  "trimmedMs": 5126,
  "tracks": [
    { "participantId": "p1", "offsetMs": 0,   "fallback": null },
    { "participantId": "p2", "offsetMs": 548, "fallback": null, "guided": true, "foundBy": "relaxed" },
    { "participantId": "p3", "offsetMs": 1290, "fallback": null, "guided": true, "foundBy": "voice" }
  ]
}
```

| 필드 | 뜻 |
|---|---|
| `tracks[].foundBy` | 없음 = 정식 기준으로 찾음 / `relaxed` = 느슨한 기준 (한 음만, 3번 중 2번) / `voice` = 비프는 못 찾고 **안내 음성 위치로 계산** |
| `level` | 결과 음량 맞추기: `dynamic`(구간별, 기본) / `loudnorm`(전체) / `off` |

`trimmedMs` 처리는 **그대로**다. STT 타임스탬프에 `trimmedMs` 를 더하면 원래 녹음 기준 시각이 된다.

## 4. 재작업 (`POST /v1/merge/{jobId}/retry`) — 꼭 확인

재작업 본문의 `files` / `output` 은 **둘 다 선택**이다. 넣은 것만 바뀌고, 안 넣은 것은 **처음 요청 때 주소를 그대로** 쓴다.
처음 주소는 시간이 지나면 만료되므로, **시간이 지난 작업은 다운로드·업로드 주소를 모두 새로** 넣어야 한다.
그렇지 않으면 MinIO 가 `AccessDenied` 로 거절한다 (10/23 현장에서 실제로 발생).

```json
POST /v1/merge/{jobId}/retry
{
  "files": [
    { "participantId": "p1", "getUrl": "서명된 새 다운로드 주소" },
    { "participantId": "p2", "getUrl": "서명된 새 다운로드 주소" }
  ],
  "output": { "putUrl": "서명된 새 업로드 주소" }
}
```

- 주소는 **서명이 붙은 presigned URL** 이어야 한다. `?X-Amz-Algorithm=...&X-Amz-Signature=...` 가 없는 주소는 안 된다.
- 업로드 주소는 **`x-amz-meta-originalname` 을 포함해 서명**해야 한다 (02 문서 5절).
- 실패 원인은 작업 조회의 `error.message` 로 구분한다: `download failed ...` = 다운로드 주소, `upload failed ...` = 업로드 주소.
