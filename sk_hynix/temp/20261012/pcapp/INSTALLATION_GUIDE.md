## 다운로드

배포받은 파일 중 하나를 다운로드하세요:
- `timbloRecApp-1.0.0-arm64.dmg` (권장)
- `timbloRecApp-1.0.0-arm64-mac.zip`

> **참고**: Apple Silicon (M1/M2/M3) Mac 전용입니다.

---

## 설치 방법

### DMG 파일 사용 시

1. `timbloRecApp-1.0.0-arm64.dmg` 파일 더블클릭
2. 열린 창에서 `timbloRecApp.app`을 `Applications` 폴더로 드래그
3. 설치 완료

### ZIP 파일 사용 시

1. `timbloRecApp-1.0.0-arm64-mac.zip` 압축 해제
2. `timbloRecApp.app`을 `Applications` 폴더로 이동
3. 설치 완료

## 앱 실행하기

### ⚠️ 중요: 첫 실행 시 필수 작업

macOS 보안 정책으로 인해 개발자 인증서가 없는 앱은 추가 설정이 필요합니다.

### 방법 1: 터미널 명령어 (권장 - 가장 빠름)

1. **터미널 실행** (`응용 프로그램 → 유틸리티 → 터미널.app`)

2. **다음 명령어 복사하여 실행:**

```bash
xattr -cr /Applications/timbloRecApp.app
```

3. Enter 키 입력 (비밀번호 입력 필요 없음)

4. **앱 실행**: `Applications` 폴더에서 `timbloRecApp` 더블클릭

5. **마이크 권한 허용**: 첫 실행 시 마이크 접근 권한 팝업이 나타나면 **"확인"** 클릭

---

### 방법 2: 시스템 설정 (터미널 사용이 어려운 경우)

1. **앱 실행 시도**: `Applications` 폴더에서 `timbloRecApp` 더블클릭

2. **에러 메시지 표시**:
   ```
   "timbloRecApp"이(가) 손상되었기 때문에 열 수 없습니다.
   ```
   → **"확인"** 클릭

3. **시스템 설정 열기**:
   - 화면 좌측 상단 Apple 로고  클릭
   - **"시스템 설정..."** 선택

4. **개인정보 보호 및 보안**:
   - 왼쪽 메뉴에서 **"개인정보 보호 및 보안"** 클릭
   - 아래로 스크롤

5. **앱 실행 허용**:
   - 하단에 다음 메시지 확인:
     ```
     "timbloRecApp"은(는) 개발자를 확인할 수 없기 때문에 차단되었습니다.
     ```
   - **"확인 없이 열기"** 버튼 클릭
   - 확인 팝업에서 **"열기"** 클릭

6. **앱 다시 실행**: `Applications` 폴더에서 `timbloRecApp` 더블클릭

7. **마이크 권한 허용**: 첫 실행 시 마이크 접근 권한 팝업이 나타나면 **"확인"** 클릭

## 문제 해결

### Q1. "확인 없이 열기" 버튼이 보이지 않아요

**원인**: 앱을 한 번도 실행 시도하지 않았거나, 시스템 설정을 너무 빨리 열었습니다.

**해결**:
1. 앱을 실행 시도하고 에러 메시지에서 "확인" 클릭
2. 10초 정도 기다린 후 시스템 설정 확인
3. 여전히 안 보이면 **방법 1 (터미널 명령어)** 사용

---

### Q2. 앱은 실행되는데 마이크가 작동하지 않아요

**원인**: 마이크 권한이 거부되었거나 설정되지 않았습니다.

**해결**:
1. **시스템 설정** 열기
2. **개인정보 보호 및 보안** → **마이크** 선택
3. 오른쪽에서 **`timbloRecApp`** 찾아서 체크박스 활성화
4. 앱 재시작

**참고**: 마이크 탭에 앱이 나타나지 않으면:
- 앱을 완전히 종료 (⌘Q)
- 앱 재실행하여 마이크 권한 팝업 다시 표시

---

### Q3. 터미널 명령어 실행 시 "Operation not permitted" 에러

**원인**: 터미널이 앱에 접근할 권한이 없습니다.

**해결**:
1. **시스템 설정** → **개인정보 보호 및 보안** → **전체 디스크 접근 권한**
2. **터미널.app** 찾아서 체크박스 활성화
3. 터미널 재시작 후 명령어 다시 실행

또는 **방법 2 (시스템 설정)** 사용

---

### Q4. 앱이 계속 "손상되었다"고 나와요

**원인**: quarantine 속성이 제대로 제거되지 않았습니다.

**해결**:
```bash
# 더 강력한 명령어 사용
sudo xattr -d com.apple.quarantine /Applications/timbloRecApp.app
```
관리자 비밀번호 입력 후 앱 실행

---

### Q5. 앱이 실행 중 갑자기 종료돼요

**원인**: Helper 프로세스 권한 문제일 수 있습니다.

**해결**:
```bash
# 앱 내부의 Helper에도 권한 부여
xattr -cr /Applications/timbloRecApp.app/Contents/Resources/helpers/macos/AudioHelper.app
```

앱 재시작

---

### Q7. 정식 서명된 버전은 언제 나오나요?

**답변**: Apple Developer Program 인증 후 정식 배포 예정입니다. 
정식 버전은 이러한 보안 경고 없이 바로 실행 가능합니다.

## 시스템 요구사항

- **운영체제**: macOS 15.0 (Sequoia) 이상 **[필수]**
- **프로세서**: Apple Silicon (M1/M2/M3/M4)
- **메모리**: 4GB RAM 이상 권장
- **저장공간**: 500MB 이상
- **권한**: 마이크 접근 권한 필요

> ⚠️ **중요**: 이 앱은 macOS 15 (Sequoia) 이상에서만 작동합니다. 이전 버전의 macOS에서는 실행되지 않습니다.
