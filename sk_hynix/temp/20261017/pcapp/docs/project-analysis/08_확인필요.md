> - **[확인됨]** 소스를 직접 읽어 동작을 확인함. 실제 실행으로 재현해 보지는 않음

## D. 정리 대상 (동작 영향 없음)

- **preload 에만 있고 핸들러가 없는 채널**: `mark-deleted`, `list-pending-uploads`, `mark-uploaded`, `list-jobs`, `maximize-window`
- **안 쓰는 기능**
  - 메모·태그 (DB 함수, IPC, preload 가 남아 있음)
  - `deep-link` 렌더러 이벤트
  - `ipc/handleWindow.js` (전체 주석)
  - `testPage.html`, `styles.css`
  - 아이콘 일부
- **이름이 같은 채널**: `dbAPI.deleteRecording(id)` 와 `electronAPI.deleteRecording(dir)` 이 같은 `delete-recording` 채널을 쓴다(main 은 dir 로 해석)
- **recording.js 중복 정의**: `updateTopButtonIcon`·`setTopState`·`toggleTopState`·`markSelected` 가 두 번씩 정의되어 있다(나중 것이 이김)
- **주석과 코드가 다른 곳**
  - `encryption_enabled:"true"` 옆 주석은 "개발 중에는 OFF"
  - `set_debug_files` 옆 주석은 "활성화"인데 값은 false
- **Windows 헬퍼의 안 쓰는 코드**
  - 옛 AEC 경로(`aecBackend`, NLMS)와 여러 보조 함수
  - `recording_stopped` 의 mic/sys 샘플 수는 디버그 파일을 켤 때만 올라간다
- **헬퍼 이벤트 형식이 OS 마다 다름** (mac 은 범위 밖이라 참고만)
  - `segment_config_set` 의 디스크 키: Windows `disk_status`, mac `status`
  - `waveform.amplitudes` 가 배열이 아니라 문자열
  - `segment_ready.size_bytes` 의미: Windows 는 평문 크기, mac 은 실제 파일 크기
- **헬퍼 로그 설정**: Windows 헬퍼 로그는 경고 이상만 기록된다. 문제 분석에 INFO 가 필요하면 `Logger.h` 의 `_DEBUG_LOG` 를 켜고 다시 빌드해야 한다
- **macOS 헬퍼 문제** (mac 은 "실행 가능" 수준이라 참고만)
  - 명령 순서 비보장
  - 녹음하지 않을 때 버퍼가 계속 커짐
  - 상태 없는 리샘플러
  - 캡처 중복 가능성
  - 녹음 파일이 `/tmp` 에 저장됨
