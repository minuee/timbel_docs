# 하울링 재시험 — 0.0.7 파형 맞추기 (2026-11-09 현장)

작성 2026-11-06 · 시험 2026-11-09 (직접 방문)

## 왜 다시 시험하나

11/05 회의(4명, `meet_20261105`) 12가지 설정 시험 결과, **모든 조합에서 울림이 심했다.**
그나마 나았던 것은 `level_off__drift_off__automix_20db`, `level_off__drift_on__automix_20db`.

| 시험에서 알게 된 것 | 뜻 |
|---|---|
| 두 파일 모두 `level_off` | 음량 맞추기가 말 사이 울림까지 키운다 → **0.0.7 부터 기본 끔** |
| 드리프트 켜도 꺼도 비슷 | 드리프트 보정은 원인 아님 |
| 설정을 다 꺼도 울림 | 원인은 설정이 아니라 **시간 맞추기 정밀도** |

`skHynix` 브랜치 소스(하울링 없음)와 비교하니 **더하는 방식은 똑같고**, 다른 점은 하나였다.
그 소스는 **목소리 파형끼리 맞대 ms 단위로 다시 맞췄고**, 지금 소스는 싱크음 시작점만으로 맞춘다.
같은 방 폰 4대는 같은 목소리를 모두 녹음하므로, 수 ms~수십 ms만 어긋나도 더하면 울리고
0.1초를 넘으면 STT 가 같은 단어를 두 번 적는다("안녕안녕").

**0.0.7 은 싱크음으로 맞춘 뒤 파형으로 한 번 더 맞춘다.** 같은 소리가 없는 트랙(다른 장소)은
움직이지 않으므로, 장소가 달라도 병합되는 지금 조건은 그대로다.

## 4. 로그 숫자 보기

```bash
cat /data/timbel/howling_test/results_007_*/meet_20261105/merged_007.log
```

`merge_refine` 줄에서 볼 값:

| 값 | 뜻 | 정상 |
|---|---|---|
| `windows` | 비교한 구간 수 | 8 |
| `linked` | 파형으로 묶인 폰 | 같은 방이면 **4대 모두** |
| `correctionMs` | 폰별로 고친 ms (양수 = 늦던 폰을 당김) | 기준 폰 0, 나머지는 몇~수십 |
| `pairs[].agree` / `used` | 같은 값이 나온 구간 수 / 비교된 구간 수 | agree 3 이상이어야 적용 |

`merged_007.json` 의 `alignment.refine.pairs[].lags` 에는 **구간별로 잰 값**이 다 있다.
같은 쌍에서 앞쪽 구간과 뒤쪽 구간 값이 크게 다르면 → 녹음 중간에 어긋남이 바뀐 것.

**숫자로 판단하기**

| 보이는 것 | 판단 |
|---|---|
| `correctionMs` 가 수~수십 ms, 소리가 깨끗해짐 | ✅ 원인 확인. 5절대로 운영 반영 |
| `correctionMs` 가 수십 ms 인데 여전히 울림 | 어긋남은 고쳤으나 다른 원인이 남음 → 숫자·느낌 들고 복귀 |
| `correctionMs` 가 거의 0 | 시간은 원래 맞았다 → 원인은 다른 곳. 들고 복귀 |
| `linked` 에서 빠진 폰이 있음 | 그 폰은 파형이 맞지 않아 그대로 둠(잡음·먼 거리·잡음 제거). 그 폰 이름 기록 |
| 구간별 `lags` 가 앞뒤로 크게 다름 | 녹음 중 끊김 → 구간별 보정 필요. 들고 복귀 |

## 5. 결과가 좋으면 — 운영 반영

시험 스크립트는 **시험하는 동안만** 설정을 바꾸고 끝나면 원래 `.env` 로 되돌린다.
그런데 운영 `.env` 에는 예전 예시대로 `MERGE_LEVEL=dynamic` 이 적혀 있을 가능성이 크다.
**이 줄을 직접 고쳐야 운영에 적용된다.**

```bash
cd /data/timblo/mobile-sync-server
grep -E '^(MERGE_LEVEL|ALIGN_REFINE)=' .env     # 지금 값 확인
sed -i 's/^MERGE_LEVEL=.*/MERGE_LEVEL=off/' .env
grep -E '^(MERGE_LEVEL|ALIGN_REFINE)=' .env     # MERGE_LEVEL=off 확인
docker compose --env-file .env up -d
```

- `ALIGN_REFINE` 줄은 없어도 된다(기본 켜짐). `ALIGN_REFINE=0` 이 있으면 지운다.
- 반영 후 실제 앱으로 짧은 회의 하나를 녹음·병합해 한 번 더 들어 본다.
