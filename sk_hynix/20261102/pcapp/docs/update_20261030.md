## 3. 로그인 방식 정리 + [시스템 로그인] 버튼 (화면만)

- 고객사: 1번(아이디/비밀번호)은 쓰기 어렵다고 함. 3번째 방식으로 SSO 엔진(TmTray 같은, Windows 로그온 정보 기반) 추가.
- **1번 사번·비밀번호:** 지우지 않고 기존 설정 `EMPNO_LOGIN_ENABLED` 로 켜고 끈다. 지금은 **true(보임)** 그대로.
- **2번 MyAccess(OAuth):** 그대로.
- **3번 시스템 로그인 (새로):** MyAccess 버튼 바로 아래 **[시스템 로그인]** 버튼(같은 모양). 설정 `SYSTEM_LOGIN_ENABLED`, 기본 **true(보임)**.
  - 누르면 메인 프로세스 `auth:system-login` 을 부른다. **엔진 매뉴얼이 아직 없어 지금은 항상 "시스템 로그인은 준비 중입니다." 만 나온다.**
  - 엔진 연동 방식이 정해지면 `handleAuth.js` 의 `auth:system-login` 안 TODO 자리에 구현한다(받은 값 → 서버 검증·토큰 교환 → 기존 약관 확인 흐름).
  - 로그 서버에 `login_attempt` / `login_failed`(method `system`, reason `system_login_not_ready`) 가 남는다.
- 끄고 싶으면 `app.config.json` 에서 `EMPNO_LOGIN_ENABLED` / `SYSTEM_LOGIN_ENABLED` 를 `false` 로.
