# 음성 병합 서버 0.0.4 변경 안내 — API(master-api) 담당자용

> 2026-10-22 · master-api 담당자 전달용
> 작성: recog 음성병합 서버 팀
> 전체 규격은 `02_API정의서_음성병합.md` (이 문서는 0.0.3 → 0.0.4 에서 바뀐 것만)

## 1. 요약

| 구분 | 내용 | master-api 할 일 |
|---|---|---|
| 요청 옵션 추가 | `options.syncSound` — 앱이 울린 싱크음 종류 | **앱과 맞춰 전달** (아래 2.1) |
| 요청 옵션 추가 | `options.automix` — 울림·반복음 제거 (기본 켜짐) | 보통은 안 보내도 됨 |
| 기본값 변경 | `options.beepSource` 기본 `leader` → **`all`** | **지금처럼 방장만 울리면 `"leader"` 를 명시** |
| 응답 추가 | `alignment.syncSound`, `alignment.automix`, `alignment.drift`, `tracks[].guided` | 기록·로그용. 처리 필수 아님 |
| 결과 파일 | 종료 싱크음이 있으면 **그 직전에서 끝난다** | 없음 (`trimmedMs` 처리 방식은 그대로) |
| 서버 로그 | `merge_done` 에 **결과 파일 위치(`output`)** 추가 | 없음 |

**하위 호환**: 새 옵션을 하나도 안 보내도 0.0.3 과 같은 방식으로 동작한다
(`beepSource` 기본값만 예외 — 1.3 참조).

## 2. 요청 (`POST /v1/merge`)

```json
"options": {
  "align": "none",
  "beepSource": "leader",
  "syncSound": "beep",
  "automix": true
}
```

### 2.1 `syncSound` — 앱이 울린 싱크음 (신규)

| 값 | 소리 |
|---|---|
| `"beep"` (기본) | 3연타 비프 (지금 쓰는 것) |
| `"voice"` | 안내 음성 "음성녹음을 시작합니다" (종료 때 "녹음을 종료합니다") |
| `"jingle"` | 5음 로고 멜로디 |

- **서버는 이 값 한 가지만 찾는다.** 앱이 실제로 울린 소리와 다르면 못 찾고 정렬이 `none` 으로 떨어진다.
- 앱이 안내 음성 + 비프(또는 징글)를 같이 울리면 → **비프(징글) 값**을 보낸다.
- 앱이 어느 소리를 쓸지는 앱 담당자와 정해서, 그 값을 그대로 넘겨 주면 된다.

### 2.2 `automix` — 울림·반복음 제거 (신규, 기본 `true`)

작은 방에서는 모든 폰이 모든 목소리를 녹음해서, 그대로 합치면 같은 말이 폰 수만큼 겹쳐 울린다.
오토믹서는 순간마다 말하는 사람 앞의 폰만 살리고 나머지를 최대 -20dB 줄인다.
**보통은 안 보내면 된다.** 비교 테스트할 때만 `false`.

### 2.3 ⚠️ `beepSource` 기본값 변경

| 0.0.3 | 0.0.4 |
|---|---|
| 안 보내면 `leader` | 안 보내면 **`all`** |

지금 앱은 **방장만** 비프를 울리므로 `"beepSource": "leader"` 를 **명시**해 주세요.
안 보내도 정렬은 되지만, 앞에서 잘리는 길이(`trimmedMs`)가 0.3초 더 길어진다.

## 3. 응답 (`GET /v1/merge/{jobId}` 완료 시) — 추가된 필드

```json
"alignment": {
  "mode": "beep",
  "beepSource": "leader",
  "syncSound": "beep",
  "automix": true,
  "trimmedMs": 5384,
  "tracks": [
    { "participantId": "p1", "offsetMs": 0,   "fallback": null },
    { "participantId": "p2", "offsetMs": 526, "fallback": null, "guided": true }
  ],
  "drift": {
    "reference": "p2",
    "endFound": 2,
    "ppm": { "p1": 312.4, "p2": 0.0 },
    "corrected": ["p1"],
    "endTrimmed": true
  }
}
```

| 필드 | 뜻 |
|---|---|
| `syncSound` | 요청값을 되돌려준 것 |
| `automix` | 오토믹서가 실제로 적용됐는지 |
| `tracks[].guided` | 1차로 못 찾은 비프를 **완화된 2차 탐색**으로 찾은 트랙 (방장 비프를 멀리서 약하게 받은 폰 등) |
| `drift.ppm` | 폰별 녹음 시계 오차. 앱이 **종료 싱크음**을 울려야 값이 나온다. 없으면 비어 있고 보정도 안 한다 |
| `drift.endTrimmed` | 결과 파일을 종료 싱크음 직전에서 잘랐는지 |

**`trimmedMs` 처리는 그대로다.** STT 타임스탬프에 `trimmedMs` 를 더하면 원래 녹음 기준 시각이 된다.
뒤쪽을 자르는 것은 타임스탬프에 영향이 없다.

## 4. 서버 로그 — 결과 파일 위치

이전에는 다운로드한 원본만 로그에 나오고 **업로드한 결과 파일은 안 나와서** 찾기 어려웠다.
이제 완료 줄에 나온다 (presigned 서명은 지우고 경로만).

```json
{"event": "merge_done", "job": "mrg_...", "room": "R-...", "alignMode": "beep",
 "output": "http://timblo-minio:9000/default.timblo.io/<kms>/<fileKey>",
 "originalname": "R-20261022-001_merged.flac", ...}
```
