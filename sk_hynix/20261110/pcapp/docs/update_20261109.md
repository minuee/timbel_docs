## 2. 화면 언어: 한국어·English 두 개

- 언어 선택(로그인·마이크 테스트 화면 아래 선택 상자, 녹음 화면 설정 → 언어)에 **한국어 / English** 만 나온다.
- `MULTI_LANG_ENABLED` 기본값을 true 로 바꿨다. 설정에 없어도 언어 선택이 보인다.
- 고른 언어는 `userData/language.json` 에 저장돼 **앱을 다시 켜도 유지된다**(집에서 저장 → 재시작 → 읽기 확인함). 로그아웃은 언어를 건드리지 않는다.
- 예전에 일본어·중국어를 골라 둔 PC 는 다음 실행부터 한국어로 시작한다.
- `ja.json`, `zh-CN.json` 은 지우지 않았다(다시 열 때 `i18n.js` 의 `LANGUAGES` 주석만 풀면 됨). 그래서 새 문구도 4개 파일에 모두 넣었다.
- 업로드 팝업의 **요약 언어**(한국어/영어/일본어/중국어)는 화면 언어와 별개라 그대로다.

## 3. AI회의록 권한 없음 안내

**동작**
- 로그인(사번·MyAccess·테스트 로그인·로그인 유지 복원) 직후, 약관 확인 다음에 권한을 확인한다.
- 권한이 없으면 → 로그아웃 → 로그인 화면에 팝업:
  > **권한 안내 메시지**
  > AI회의록을 이용할 권한이 없으십니다. myAccess에 AI회의록 권한을 승인받은후 다시 시도해주십시요
  > [확인]
- [확인] → 앱 종료. 닫기 버튼은 없다.
- 확인에 실패(네트워크 오류·모르는 응답)하면 **막지 않고 통과**한다(약관 확인과 같은 원칙).

**⚠️ 권한 확인 API 는 백엔드가 새로 만드는 중 → 지금은 흉내만**
- `ACCESS_CHECK_PATH` 가 비어 있으면(지금) **확인하지 않고 통과**한다. 그래서 이번 반영으로 로그인이 막히는 일은 없다. 로그에 `access_check_skipped` (`error: not_configured`) 가 남는다.
- 팝업 확인용: `.env` 에 `ACCESS_CHECK_MOCK=denied` → 서버를 부르지 않고 "권한 없음"으로 본다. **운영 빌드에는 절대 넣지 않는다.**
- API 가 확정되면 할 일:
  1. `ACCESS_CHECK_PATH`(·필요하면 `ACCESS_CHECK_METHOD`)를 `app.config.json` 에 넣는다. 서버 주소는 로그인한 서버(업로드와 같은 곳), 토큰은 자동으로 붙는다.
  2. 응답 모양이 아래 가정과 다르면 `authService.js` `checkMinutesAccess` 의 **"★ 응답 해석"** 부분만 고친다.
     - 지금 가정: 서버 공통 형식 `{ httpCode, message, data }` 에서 `httpCode` 403 이거나 `data.hasAuth` / `data.authorized` / `data.allowed` 가 false → 권한 없음, `httpCode` 200 → 권한 있음.
  3. 백엔드 담당자에게 받을 것: 경로·메서드, 권한 있음/없음 응답 예시(본문 그대로).

## 4. 녹음 중 미니(축소) 모드

```
평소: [SKHynix AI 회의록][⚙]            [⤡축소][📌][—]
미니: [SKHynix AI 회의록] ● 녹음 중 00:12:34     [⤢확대]
```
- 헤더 오른쪽(핀 왼쪽) **[축소]** 버튼. **녹음 중·일시정지일 때만** 보인다.
- 누르면 창이 가로 360 그대로, **높이 = 헤더(약 44px)** 로 줄고 **항상 위가 자동으로 켜진다.**
- 미니에서는 제목 · 상태(● 녹음 중 = 빨간 점 깜빡임 / ● 일시정지 = 회색) · 진행 시간 · [확대] 만 보인다. 헤더를 끌어서 옮길 수 있다.
- [확대] → 원래 크기(360×320), 항상 위는 **들어가기 전 설정**으로 되돌린다.
- 녹음이 끝나면(오류·저장 공간·장치 끊김·3시간) 자동으로 원래 크기로 돌아온다(안내 팝업을 볼 수 있게).
- 로그: `mini_mode_entered`, `mini_mode_exited` (reason: `user` / `recording_ended`).
