# AM-Tray → 앱 윈도우 메시지 (원본: window-message.md 위쪽)

## 1. 로그인 알림
| 항목 | 값 |
|---|---|
| Message | `WM_COPYDATA` (`0x004A`) |
| wParam | 로그인 환경 식별값 — 운영 `30001`, 개발 `31001` |
| lParam | `COPYDATASTRUCT*` |
| └ dwData | 미사용 |
| └ cbData | lpData 크기(byte) |
| └ lpData | 사용자 ID 해시값 (SHA-256) |

## 2. 로그아웃 알림
| 항목 | 값 |
|---|---|
| Message | `WM_USER` (`0x0400`) + 연동 환경 식별값 → 운영 `0x0400 + 30001`, 개발 `0x0400 + 31001` |
| wParam | 로그아웃 환경 식별값 — 운영 `30001`, 개발 `31001` |
| lParam | 미사용 |

## 메모
- 로그인 알림에는 사번이 아니라 **사번의 SHA-256 해시**만 온다 → "로그인 끝남" 신호로만 쓰고 토큰은 `GetSystemTokenIT` 를 다시 불러 받는다.
