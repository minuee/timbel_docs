# 운영 배포 1.0.3 + "크기 파도·처음 울림·잡음" 시험

작성 2026-11-19 (현장 시험·배포 2026-11-25)

## 1.0.3 은 무엇이 바뀌었나

1.0.2 현장 시험과 고객 회의에서 **문장 반복과 하울링은 거의 사라졌다**(이전보다 많이 좋아졌다는 평). 남은 "옥의 티" 셋을 고친 버전이다.

| 남은 것 (11/19) | 원인 | 1.0.3 |
|---|---|---|
| 한 사람이 계속 말하는데 **파도처럼 작아졌다 커졌다** | `select` 는 순간마다 폰 하나를 **그 폰 원본 크기로** 쓴다. 같은 목소리도 가까운 폰엔 크게, 먼 폰엔 작게 들어 있어서 폰이 바뀔 때마다 크기가 계단처럼 바뀐다. 뒤의 음량 맞추기(`dynamic`)는 약 15초 단위라 계단을 둥글게만 만든다 | **폰이 바뀔 때 크기 이어 붙이기** (`AUTOMIX_LEVEL_MATCH=1`, 기본 켬). 폰이 들리는 구간마다 그 구간 말소리 크기를 재서 같은 크기로 맞춘다. 말 없는 구간은 그 폰 전체 값을 써서 잡음을 키우지 않는다 |
| **처음 1분 정도만** 울린다 | 목소리 맞추기는 회의 전체를 직선 하나로 맞춘다. 한 폰의 **앞부분만** 수십 ms 어긋나 있으면 그대로 남아, 폰이 바뀔 때 짧게 겹쳐 울림처럼 들린다 (추정) | **처음 구간 다시 재기** (`ALIGN_HEAD_CHECK=1`, 기본 켬). 회의 앞 2분을 20초씩 다시 재서, 앞부분만 꾸준히 어긋난 폰은 바뀐 지점 근처 가장 조용한 순간에서 앞부분만 옮겨 붙인다. **어긋남이 없으면 아무것도 안 한다** |
| 원본에 있는 **잡음** | 에어컨·컴퓨터 팬 같은 꾸준한 잡음. 음량 맞추기가 말 없는 순간에 같이 키운다 | **폰별 잡음 제거** (`MERGE_DENOISE`, 기본 0=끔). 폰마다 잡음 크기를 재서 섞기 전에 그 아래를 줄인다 |

처음 1분 울림의 원인은 **추정**이다. 그래서 처음 구간 다시 재기는 잰 값을 요약에 그대로 보여 준다 — 고쳐지지 않더라도 다음에 원인을 좁힐 수 있다.

**그대로인 것:** 오토믹서 `select`(유지 1000 / 전환 6), 음량 맞추기 `dynamic`, 목소리 맞추기 ±4초, 비프 지우기. 소리를 더하는 방식은 하나도 늘지 않았으므로 **하울링이 다시 생기지 않는다.**

### 여기서 미리 확인한 것

| 확인 | 결과 |
|---|---|
| 크기 이어 붙이기 — 같은 방 폰 3대를 흉내 낸 녹음 | 1초 단위 말소리 크기의 흔들림 **2.2dB → 1.4dB**. 폰 전환 횟수는 그대로(21번) |
| 처음 구간 — 한 폰의 앞 70초만 40ms 늦춘 녹음 | 40ms 를 찾아 72초 지점에서 이어 붙임 → 다시 재면 **남은 어긋남 0ms**. 47초·95초에서 바뀐 경우도 같음. 어긋남이 없는 녹음은 손대지 않음 |
| 잡음 제거 — 세 폰에 팬 소리(분홍 잡음)를 섞은 녹음, 결과 파일에서 | 잡음 -42dB → **-51dB (12)** / **-53dB (20)**, 말소리 크기는 -12.7dB 그대로 |
| 1.0.3 이미지로 `howling_test_103.sh` 를 직접 돌림 | 4가지 경우 모두 병합 완료. `.env` 에 200 이 적혀 있어도 시험은 4000 으로 돈다 |

## 0-1. 시험 전 운영 `.env` 기준값

시험 도구는 **새 기능 셋(크기맞추기·잡음제거·처음재기)과 목소리 맞추기 범위(4000)만** 스스로 바꾸고, 나머지는 운영 `.env` 를 따른다.
11/18 에 맞춰 둔 값 그대로면 된다.

| 항목 | 값 | 비고 |
|---|---|---|
| `MERGE_AUTOMIX` | 1 | |
| `AUTOMIX_MODE` | **select** | 크기 이어 붙이기는 select 에서만 동작한다. 다르면 요약에 주의가 뜬다 |
| `AUTOMIX_HOLD_MS` / `AUTOMIX_SWITCH_DB` | 1000 / 6 | |
| `MERGE_TRACK_GAIN` | 0 | 크기 이어 붙이기가 켜지면 어차피 쓰이지 않는다 |
| `MERGE_LEVEL` | dynamic | |
| `ALIGN_REFINE` / `ALIGN_REFINE_MAX_MS` | 1 / **4000** | 1.0.2 배포 때 고쳤으면 그대로 |
| `BEEP_SCRUB` | 1 | |
| `AUTOMIX_LEVEL_MATCH` | 1 | **1.0.3 새 항목.** 줄이 없어도 기본으로 켜져 있다 |
| `ALIGN_HEAD_CHECK` | 1 | **1.0.3 새 항목.** 줄이 없어도 기본으로 켜져 있다 |
| `MERGE_DENOISE` | 0 | **1.0.3 새 항목.** 시험 결과를 듣고 정한다 (2-③) |

설치할 때 새 항목 셋이 `.env` 에 없다고 경고가 나와도 괜찮다 (기본값으로 돈다).

## 1. 먼저 시험 — 운영은 그대로 두고

```bash
cd /data/timblo/mobile-sync-server                  # 설치 폴더
sha256sum -c mobile-sync-server_1.0.3_amd64.tar.sha256     # "OK"
docker load -i mobile-sync-server_1.0.3_amd64.tar          # 이미지만 올린다. 운영 컨테이너는 그대로
chmod +x howling_test_103.sh
IMAGE=mobile-sync-server:1.0.3 ./howling_test_103.sh /data/timbel/howling_test
```

- `.txt` 로 가져왔으면 `mv howling_test_103.txt howling_test_103.sh`, `$'\r': command not found` 가 나오면 `sed -i 's/\r$//' howling_test_103.sh`
- 설치 폴더가 다르면 앞에 `INSTALL_DIR=<설치 폴더>` 를 붙인다
- **1.0.2 이전 이미지로 돌리면** "1.0.3 이전 버전이다" 하고 멈춘다
- 시험 폴더 구조는 101·102 와 같다 (회의 폴더마다 폰별 원본 flac 2개 이상). **처음 1분 울림·크기 파도가 있던 회의**를 넣는다

### 기본 경우 (자동으로 전부 돈다)

경우 하나 = `크기맞추기:잡음제거dB:처음재기`

| 순서 | 경우 | 결과 이름 | 보는 것 |
|---|---|---|---|
| 1 | `0:0:0` | `L0_N0_H0` | **1.0.2 와 같음** — 지금 들리는 것과 같아야 한다 (비교 기준) |
| 2 | `1:0:1` | `L1_N0_H1` | **1.0.3 기본값.** 크기 파도·처음 울림이 줄었는지 |
| 3 | `1:12:1` | `L1_N12_H1` | + 잡음 제거 보통 |
| 4 | `1:20:1` | `L1_N20_H1` | + 잡음 제거 강하게 |

경우 바꾸기 (예: 잡음 제거 세기를 더 촘촘히):

```bash
IMAGE=mobile-sync-server:1.0.3 CASES="1:8:1 1:16:1" ./howling_test_103.sh /data/timbel/howling_test
```

이미 만든 경우는 건너뛴다 (다시 하려면 `FORCE=1`). 결과는 `results_103/<회의>/L*.flac`.

### 끝나면 화면에 요약 → **사진으로 찍어 오면 된다**

```
================ 요약 (이 화면을 사진으로 찍어 오면 된다) ================
[noisy]  A.flac B.flac C.flac
L1_N12_H1:
    연결      ["f1", "f2", "f3"]   최종 {"f1": 1450, "f2": 0, "f3": 2750}
    처음어긋남 {"f2": [null, null, null, -0.1, null, null], "f3": [0.0, null, 0.0, 0.0, null, -0.1]}
    처음고침  {}
    크기      {"min": -7.3, "median": -3.0, "max": 2.8}  말없음 0
    잡음크기  {"f1": -46.0, "f2": -46.1, "f3": -46.0}  (폰별 dBFS, 이 아래를 줄였다)
    지운비프  {"f1": 3, "f2": 3, "f3": 3}   전환 23
```

(위는 여기서 팬 소리를 섞은 녹음으로 돌린 실제 화면.)

### 숫자 읽는 법

| 값 | 뜻 |
|---|---|
| `처음어긋남` | 폰별로 회의 앞 2분을 20초씩 잰 남은 어긋남(ms, 기준 폰 대비). `null` = 그 20초엔 말이 없거나 같은 소리가 약해 못 잼. **10 이상이 두 번 넘게 이어지면** 앞부분이 어긋나 있던 것 |
| `처음고침` | 앞부분만 옮겨 붙인 폰. `shiftMs` 옮긴 양, `atSec` 그 폰 원본에서 이어 붙인 초. `{}` = 고칠 것이 없었다 |
| `크기` | 폰이 바뀐 구간마다 준 크기(dB)의 최소/중간/최대. 차이가 클수록 원래 크기 계단이 컸던 것 |
| `말없음` | 말이 없어 폰 전체 값을 쓴 구간 수 |
| `잡음크기` | 잡음 제거를 켠 경우, 폰마다 잰 잡음 크기(dBFS). -60 보다 작으면 원래 조용한 폰 |
| `주의: ...` | 사진에 꼭 |

### 들을 것

**크기가 파도치던 구간, 처음 1분, 잡음이 거슬리던 구간**을 결과끼리 번갈아 듣고 적는다.

```
                    크기 파도(없음/약간/그대로)   처음 1분 울림(없음/약간/그대로)   잡음(작다/보통/크다)   목소리 이상함(없음/물속처럼)
L0_N0_H0 (1.0.2)    ____                         ____                            ____                  ____
L1_N0_H1 (1.0.3)    ____                         ____                            ____                  ____
L1_N12_H1           ____                         ____                            ____                  ____
L1_N20_H1           ____                         ____                            ____                  ____
```

| 들리는 것 | 다음 |
|---|---|
| `L1_N0_H1` 에서 파도·처음 울림이 줄었다 | **2. 운영 배포** 로 |
| 잡음 제거 결과가 더 낫고 목소리가 멀쩡하다 | 배포 때 `.env` 에 `MERGE_DENOISE=12` (또는 20) — 2-③ |
| 잡음 제거에서 목소리가 물속처럼 들린다 | `MERGE_DENOISE=0` 으로 두거나 `CASES="1:6:1 1:8:1"` 로 더 약하게 한 번 더 |
| 처음 1분 울림이 그대로이고 `처음고침` 이 `{}` | 원인이 정렬이 아니다. 요약 사진 + 처음 1분에 무슨 일이 있었는지(사람 입장, 폰 놓기 등) 기억나는 대로 |
| 크기 파도가 그대로 | 요약의 `크기` 숫자 사진 + 파도치던 구간 시각 |

## 2. 운영 배포

### ① 설치 폴더 확인

```bash
docker inspect mobile-sync-server \
  --format '{{ index .Config.Labels "com.docker.compose.project.working_dir" }}'
```

### ② 파일 올리고 설치

```bash
cd <①에서 나온 폴더>

# 옛 tar 지우기 (안 지우면 설치가 멈춘다). 1.0.3 tar 는 지우지 않는다
rm -f mobile-sync-server_1.0.0_amd64.tar* mobile-sync-server_1.0.1_amd64.tar* mobile-sync-server_1.0.2_amd64.tar*

# 새 tar 2개, install.sh, docker-compose.yml, .env.example 을 이 폴더에 복사한 뒤
sha256sum -c mobile-sync-server_1.0.3_amd64.tar.sha256     # "OK"
chmod +x install.sh
./install.sh
```

시험(1) 때 이미 `docker load` 해 두었어도 그대로 진행하면 된다.

### ③ 잡음 제거를 켜기로 했으면

```bash
grep -q '^MERGE_DENOISE=' .env && sed -i 's/^MERGE_DENOISE=.*/MERGE_DENOISE=12/' .env || echo 'MERGE_DENOISE=12' >> .env
docker compose --env-file .env up -d                        # docker restart 로는 반영 안 된다
```

(12 대신 시험에서 고른 값. 켜지 않으면 이 단계는 건너뛴다.)

### ④ 확인

```bash
grep IMAGE_VERSION .env                                     # IMAGE_VERSION=1.0.3
curl -s http://127.0.0.1:9995/health                        # {"status": "ok", ...}
docker logs mobile-sync-server 2>&1 | grep server_start     # "version": "1.0.3" + settings
```

`settings` 에서 아래가 나와야 한다 (`(기본값)` 이 붙어도 괜찮다):

```
"AUTOMIX_LEVEL_MATCH": true   "ALIGN_HEAD_CHECK": true   "MERGE_DENOISE": 0.0 (또는 고른 값)
"ALIGN_REFINE_MAX_MS": 4000   "AUTOMIX_MODE": "select"   "MERGE_LEVEL": "dynamic"
```

병합을 한 건 해 본 뒤:

```bash
docker logs mobile-sync-server 2>&1 | grep -E 'merge_automix|merge_refine_head|merge_denoise' | tail -3
```

### 되돌리기

| 상황 | 할 일 |
|---|---|
| 1.0.3 전체에 문제 | `.env` 의 `IMAGE_VERSION=1.0.2` → `docker compose --env-file .env up -d` (옛 이미지는 남아 있다) |
| 크기 이어 붙이기만 의심 | `.env` 에 `AUTOMIX_LEVEL_MATCH=0` → `docker compose --env-file .env up -d` |
| 처음 구간 다시 재기만 의심 | `.env` 에 `ALIGN_HEAD_CHECK=0` → 같은 방법 |
| 잡음 제거만 의심 | `.env` 에 `MERGE_DENOISE=0` → 같은 방법 |
