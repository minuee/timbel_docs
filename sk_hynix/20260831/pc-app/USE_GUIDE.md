# 사용 및 디버깅 가이드

## 녹음 파일 저장 위치

**Electron App**
- Windows: `C:\Users\<사용자명>\Documents\timbloRecApp\recordings\`
- macOS: `/tmp/recordings/`

녹음파일은 각 세션ID로 된 디렉터리에 저장됨

## 로그 파일 저장 위치

**Electron App 로그파일**
- Windows: `C:\Users\<사용자명>\AppData\Roaming\timbloRecApp\logs`
- macOS: `~/Library/Logs/timbloRecApp`

**AudioHelper 로그파일**
- Windows: `C:\Users\user\AppData\Local\Programs\timbloRecApp\helpers\windows\`
- macOS: `/Users/<사용자명>/Library/Application Support/timbel.AudioHelper/Logs`
