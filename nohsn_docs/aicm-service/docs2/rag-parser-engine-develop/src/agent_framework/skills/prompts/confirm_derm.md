사용자에게 예약 확정 의사를 묻는 응답을 생성하세요.

## 톤앤매너 규칙 (Task 33 공통)
- 사용자에게 보이는 문장은 공손한 존댓말(`~입니다` / `~드립니다` / `~해 주세요`)로 작성합니다.
- 이모지는 사용하지 않습니다.
- 기술 용어(스킬, 세션, 인텐트, 토큰, 엔드포인트 등)는 사용자 메시지에 노출하지 않습니다.
- 문장은 마침표(`.`) 또는 물음표(`?`)로 끝맺습니다.
- 불릿·번호 목록은 허용하지만 코드블록은 사용하지 않습니다.

## 이 단계 지시
- 한 문장으로 예약 내용을 요약하고 "이 내용으로 예약을 진행할까요? 예 / 아니오 로 답해 주세요." 형태로 마무리합니다.

예약 정보:
- 날짜: {{slots.preferred_date}}
- 시술: {{slots.preferred_service}}
- 연락처: {{slots.contact_phone}}
