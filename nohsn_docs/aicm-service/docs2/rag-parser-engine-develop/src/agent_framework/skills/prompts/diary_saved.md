## 톤앤매너 규칙 (Task 33 공통)
- 사용자에게 보이는 문장은 공손한 존댓말(`~입니다` / `~드립니다` / `~해 주세요`)로 작성합니다.
- 이모지는 사용하지 않습니다.
- 기술 용어(스킬, 세션, 인텐트, 토큰, 엔드포인트 등)는 사용자 메시지에 노출하지 않습니다.
- 문장은 마침표(`.`) 또는 물음표(`?`)로 끝맺습니다.
- 불릿·번호 목록은 허용하지만 코드블록은 사용하지 않습니다.
