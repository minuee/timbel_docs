# 카테고리: memo (캐주얼 캡처 + 마감 관리)

자비스 패턴 — 사용자가 일상 중 흘리는 *짧은 의무·약속·할 일* 발화를 자동
캡처하고 마감/알람 관리. schedule (캘린더 약속) 도 reminder (반복 알람) 도
아닌 *capture+todo* 도메인.

## 캐주얼 발화 캡처 (★ 핵심)

다음 발화 패턴은 **메모 캡처** 의도:
- "아 맞다. 나 내일까지 보고서 제출 해야 돼. 2시 마감이야."
- "월요일에 약속 있어. 까먹지 말자."
- "내일까지 답변 주기로 했어."
- "다음주 화요일 회비 송금."
- "이번주 안에 부모님 선물 사야 돼."
- "퇴근 전에 오늘 회의록 보내야 함."

특징: "맞다", "까먹지", "해야 돼", "마감", "잊으면", "기억", "내일까지",
"퇴근 전" 같은 *단발 의무·기억 표현* + 명사구 핵심.

→
```
[{1, tool, memo.create, {
   title: "<핵심 명사구 — '보고서 제출', '회비 송금', '선물 사기', '회의록 발송' 등>",
   note: "<부연 설명 있으면, 없으면 생략>",
   deadline_at: "<ISO datetime — '내일 2시' → '<내일>T14:00:00', '월요일' → 다음 월요일 자정 등>",
   alarm_at: "<ISO datetime — 명시적 알람 시각 있으면, 없으면 생략. 마감 30분 전 자동 추천 X — 사용자 명시만>",
   raw_utterance: "<사용자 원 발화 그대로>",
   tenant_id: "$personal_tenant_id"
 }}]
```

자연어 → args 변환:
- "내일 2시 마감" → deadline_at = `<내일>T14:00:00`. ("오후 2시" 도 동일).
- "내일까지" / "오늘 안에" → deadline_at = `<해당 날짜>T23:59:00` (해당 일 종료).
- "월요일까지" → 다음 월요일.
- "다음주 화요일" → 다음 주 화요일 자정.
- "퇴근 전" → 오늘 18:00 (근무시간 모르면 기본).
- title 추출: 동사 명사구를 명사로 압축 ("보고서 제출 해야 돼" → "보고서 제출").

slot 부족 케이스:
- 마감 표현이 모호 ("나중에", "곧") → deadline_at 비워두고 그대로 등록. 사용자가
  나중에 추가할 수 있음. clarify 강제 X.
- 본문 핵심이 너무 짧으면 ("아 맞다, 그거") clarify "어떤 일이신가요?" 권장.

## 메모 조회

"메모 뭐 있어?" / "할 일 보여줘" / "마감 임박 메모" →
```
[{1, tool, memo.list, {
   tenant_id: "$personal_tenant_id",
   status: "active"
 }}]
```

"완료한 메모" → status="done". "전체" / "히스토리" → status 생략.

## 메모 완료 / 수정 / 삭제

- "보고서 제출 끝냈어" / "그 메모 완료" → memo.complete.
- "마감 미뤄. 모레로" → memo.update {id, deadline_at}.
- "그 메모 지워" → memo.delete {id}.
- 단건 식별은 history 의 직전 메모 또는 title 매칭으로. id 알 수 없으면 ask_user_clarify.

## ★ schedule vs memo 구분 (중요)

- *시각이 명확한 약속/회의/만남* → schedule (캘린더). 예: "내일 3시 김부장 미팅".
- *시각 명확한 반복 알람* → reminder. 예: "매일 8시 약 복용 알람".
- *기한이 있는 할 일·의무* (마감만 있고 회의가 아님) → memo. 예: "내일까지 보고서
  제출", "이번주 안에 회비 송금". 만남 X, 알람 반복 X, 그냥 *해야 할 것*.

발화 모호 시 우선순위: schedule (회의/만남 표현) > reminder (반복) > memo (기한
있는 할 일) > info_lookup. "마감", "끝내야", "제출" 같은 단어가 명확하면 memo.

## 응답 본문 echo (핵심 슬롯)

성공 시: title + deadline_at + (alarm_at 있으면) + 등록 완료 명시.
duplicate 시: 기존 메모 정보 (title, deadline_at) echo + "이미 등록됨".

예시 응답:
- "메모를 기록했습니다 — 보고서 제출, 마감 2026-05-07 14:00."
- "이미 비슷한 메모가 등록되어 있습니다 — 보고서 제출, 마감 2026-05-07 14:00."
- "현재 활성 메모 3건: (1) 보고서 제출 — 내일 14:00, (2) 회비 송금 — 화요일,
  (3) 선물 사기 — 이번주."
