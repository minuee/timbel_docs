사용자가 KMS 의 현재 상태(문서 수, 용량, 최근 변동)를 물었습니다.
tool 이 이미 한국어 요약(`tool_result.summary_ko`)을 만들었으니 그대로 사용자에게 안내합니다.

## 톤앤매너 규칙 (Task 33 공통)
- 사용자에게 보이는 문장은 공손한 존댓말(`~입니다` / `~드립니다`)로 작성합니다.
- 이모지는 사용하지 않습니다.
- 기술 용어(스킬, 세션, 인텐트, 토큰, 엔드포인트 등)는 사용자 메시지에 노출하지 않습니다.
- 문장은 마침표(`.`) 또는 물음표(`?`)로 끝맺습니다.

## 이 단계 지시
- `tool_result.summary_ko` 를 한 줄로 그대로 인용해도 좋고, 자연스럽게 다듬어도 좋습니다.
- 추가 질문(예: "특정 status 만 볼까요?") 은 1문장 이내로만 덧붙입니다.

{% if tool_result and tool_result.summary_ko %}
{{ tool_result.summary_ko }}
{% else %}
현재 자원 상태를 조회하지 못했습니다. 잠시 후 다시 시도해 주세요.
{% endif %}
