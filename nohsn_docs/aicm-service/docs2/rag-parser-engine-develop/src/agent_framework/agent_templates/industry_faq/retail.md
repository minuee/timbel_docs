# 소매/유통 (편의점/마트/온라인쇼핑) — FAQ Pool (sample)

> 본 문서는 *seed FAQ* 입니다. agent 만들 시 카테고리 선택하면 자동 bound.
> 사용자 (관리자) 가 자기 사업장 정보로 *수정* 후 KMS 업로드 권장.

## Q1. 영업시간 및 휴무일

**Q**: 영업시간이 어떻게 되나요?
**변형 발화**:
- 오늘 몇 시까지 해요?
- 명절에도 문 여나요?
**A**: 영업시간은 {영업시간} 입니다. 정기 휴무일은 {휴무일} 이며, 공휴일·명절 운영 여부는 카카오톡 채널을 통해 사전 공지드립니다.

## Q2. 배송 안내 및 무료 배송 조건

**Q**: 배송은 어떻게 되나요?
**변형 발화**:
- 무료 배송 기준이 있나요?
- 주문 후 며칠 만에 받을 수 있어요?
**A**: 배송 안내는 아래와 같습니다.
- 배송비: {배송비} (주문금액 {무료배송기준} 이상 시 무료)
- 출고 기준: 평일 {주문마감시간} 이전 결제 완료 시 당일 출고
- 배송 소요: 일반 {배송소요일} / 도서산간 {도서산간배송일}
빠른 배송 옵션({빠른배송옵션})도 선택 가능합니다.

## Q3. 교환 및 환불 정책

**Q**: 구매한 상품을 교환하거나 환불할 수 있나요?
**변형 발화**:
- 상품이 마음에 안 들어요
- 불량품이에요, 어떻게 해야 하나요?
**A**: 교환·환불은 수령일로부터 {교환환불기간} 이내, 미사용·미개봉·원 포장 상태의 상품에 한해 가능합니다. 신청 방법: 채팅 또는 {고객센터연락처}로 주문번호와 사유를 알려주세요. 상품 불량·오배송의 경우 왕복 배송비 없이 처리해 드립니다. 식품·위생용품 등 일부 상품은 교환·환불이 제한됩니다.

## Q4. 재고 확인 및 상품 문의

**Q**: 특정 상품 재고가 있나요?
**변형 발화**:
- 품절인데 언제 들어와요?
- 원하는 색상·용량이 없어요
**A**: 실시간 재고는 {재고조회방법} 에서 확인하실 수 있습니다. 품절 상품의 경우 상품 페이지에서 '재입고 알림'을 신청하시면 입고 시 알림을 받으실 수 있습니다. 특정 상품 입고 일정은 채팅으로 문의해 주시면 확인 후 안내드립니다.

## Q5. 포인트 및 멤버십 혜택

**Q**: 포인트나 멤버십 혜택이 있나요?
**변형 발화**:
- 회원 가입하면 뭐가 좋아요?
- 포인트 어떻게 사용해요?
**A**: 회원 가입 시 {가입혜택} 이 제공됩니다. 구매 금액의 {적립율} 가 포인트로 적립되며, {포인트사용기준} 이상 적립 시 결제에 사용 가능합니다. 등급별 추가 혜택({등급혜택})도 제공되오니 {멤버십안내링크}에서 확인해 주세요.
