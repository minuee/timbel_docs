# IT/전자기기 (수리/판매) — FAQ Pool (sample)

> 본 문서는 *seed FAQ* 입니다. agent 만들 시 카테고리 선택하면 자동 bound.
> 사용자 (관리자) 가 자기 사업장 정보로 *수정* 후 KMS 업로드 권장.

## Q1. 수리 가능 기기 및 문의 방법

**Q**: 어떤 기기를 수리해 주나요?
**변형 발화**:
- 아이폰 액정 수리 되나요?
- 삼성 노트북도 고칠 수 있어요?
**A**: 현재 수리 가능한 기기는 아래와 같습니다.
- 스마트폰: {수리가능스마트폰브랜드}
- 노트북/태블릿: {수리가능노트북브랜드}
- 기타: {기타수리가능기기}
수리 가능 여부 및 증상 진단은 카카오톡 채팅으로 기기 모델명과 증상을 알려주시면 빠르게 안내드립니다.

## Q2. 수리 비용 안내

**Q**: 수리 비용이 얼마나 드나요?
**변형 발화**:
- 액정 교체 얼마예요?
- 견적 먼저 받을 수 있나요?
**A**: 주요 수리 항목별 예상 비용은 아래와 같습니다.
- {기기명} 액정 교체: {가격1}
- {기기명} 배터리 교체: {가격2}
- {기기명} 기판 수리: {가격3}
정확한 견적은 기기 입고 후 진단 결과를 바탕으로 안내드립니다. 진단 비용({진단비용})이 발생하며, 수리 진행 시 차감됩니다.

## Q3. 수리 소요 시간 및 방법

**Q**: 수리하는 데 얼마나 걸리나요?
**변형 발화**:
- 당일 수리가 되나요?
- 택배로 맡길 수 있나요?
**A**: 수리 소요 시간은 아래와 같습니다.
- 단순 액정·배터리 교체: 당일 ({소요시간})
- 기판·소프트웨어 수리: {소요일수}
방문 수리: 직접 매장({주소})으로 방문해 주세요.
택배 수리: {택배수리방법} 으로 발송 가능합니다. 수리 완료 후 착불 반송합니다.

## Q4. 데이터 보호 및 초기화

**Q**: 수리 중 제 데이터는 안전한가요?
**변형 발화**:
- 수리 맡기면 개인정보가 노출되지 않나요?
- 수리 전 백업해야 하나요?
**A**: 수리 과정에서 불가피하게 데이터가 초기화될 수 있습니다. 수리 맡기시기 전 반드시 개인 백업을 해두시길 권장드립니다. 저희는 고객 데이터에 접근하지 않으며, 수리 완료 후 데이터 복구 지원({데이터복구서비스여부})도 가능합니다.

## Q5. 보증 및 A/S 정책

**Q**: 수리 후 보증이 되나요?
**변형 발화**:
- 수리한 부품이 또 고장나면 어떻게 해요?
- A/S 기간이 있나요?
**A**: 수리 완료 부품에 대해 {보증기간} 간 무상 A/S를 제공합니다. 동일 부위 재고장 시 무상으로 처리해 드립니다. 단, 고객 과실(침수·충격 등)로 인한 재고장은 보증에서 제외됩니다. A/S 접수는 채팅 또는 전화({전화번호})로 해주세요.
