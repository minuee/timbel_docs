# 교육 (학원/과외/교습소) — FAQ Pool (sample)

> 본 문서는 *seed FAQ* 입니다. agent 만들 시 카테고리 선택하면 자동 bound.
> 사용자 (관리자) 가 자기 사업장 정보로 *수정* 후 KMS 업로드 권장.

## Q1. 수업 시간 및 커리큘럼 안내

**Q**: 수업은 어떻게 구성되어 있나요?
**변형 발화**:
- 어떤 과목을 가르쳐 주나요?
- 레벨별 반 구성이 어떻게 되나요?
**A**: 현재 운영 중인 반 구성은 아래와 같습니다.
- {반명1}: {대상학년1} / {수업시간1} / {수업일수1}
- {반명2}: {대상학년2} / {수업시간2} / {수업일수2}
- {반명3}: {대상학년3} / {수업시간3} / {수업일수3}
레벨 테스트 후 적합한 반을 배정해 드립니다. 상세 커리큘럼은 채팅으로 문의 주세요.

## Q2. 수강료 및 결제 방법

**Q**: 수강료가 얼마고, 어떻게 결제하나요?
**변형 발화**:
- 한 달에 얼마예요?
- 카드 결제 되나요?
**A**: 수강료는 아래와 같습니다.
- {반명1}: {수강료1} / 월 ({수업횟수1}회)
- {반명2}: {수강료2} / 월
교재비는 {교재비} 가 별도 청구됩니다. 결제는 계좌이체·카드·현금 모두 가능하며, 형제 할인({형제할인내용}) 등 혜택도 제공합니다.

## Q3. 등록 및 레벨 테스트

**Q**: 등록하려면 어떻게 하나요?
**변형 발화**:
- 레벨 테스트가 있나요?
- 중간에 등록해도 되나요?
**A**: 등록은 카카오톡 채팅 또는 전화({전화번호})로 신청해 주시면 됩니다. 첫 등록 시 레벨 테스트({레벨테스트방법})를 통해 적합한 반을 안내드립니다. 월 중간 등록 시 일할 계산({일할계산여부})으로 수강료가 조정됩니다.

## Q4. 결석 및 보강 정책

**Q**: 아이가 결석하면 보강을 받을 수 있나요?
**변형 발화**:
- 아파서 못 갔는데 보충수업이 되나요?
- 보강 신청은 어떻게 해요?
**A**: 보강은 사전 연락({사전연락기한} 전)을 주신 경우에 한해 제공되며, {보강가능기간} 이내 진행됩니다. 보강 가능 시간은 {보강가능시간} 입니다. 무단 결석의 경우 보강이 제공되지 않을 수 있으니 미리 알려주세요.

## Q5. 환불 및 수강 취소 정책

**Q**: 수강을 취소하면 환불이 되나요?
**변형 발화**:
- 중간에 그만두고 싶어요
- 학원 환불 규정이 어떻게 되나요?
**A**: 학원법에 따른 환불 규정이 적용됩니다.
- 수강 시작 전: 전액 환불
- 수강 1/3 미만 경과: 수강료의 2/3 환불
- 수강 1/2 미만 경과: 수강료의 1/2 환불
- 수강 1/2 이상 경과: 환불 불가
교재비는 미사용 시 환불 가능합니다. 환불 신청은 채팅 또는 원장 상담을 통해 접수해 주세요.
