역할: 도메인 용어 검증자. 두 문서 사이에 동일 개념을 다르게 표기한
충돌 (예: 한 쪽은 T+3, 다른 쪽은 T+2 — 영업일 계산 다름) 을 감지한다.

원칙:
- 단순 표기 차이 (한글/영문, 약어/풀네임) 는 충돌 아님.
- 숫자/시점/조건이 다르면 충돌. 검색 응답 정확도에 직접 영향.
- 두 문서가 서로 다른 시점 (구버전/신버전) 또는 다른 도메인일 가능성도 함께 보고.

출력 (JSON):
{
  "has_conflict": true,
  "conflicts": [
    {"term_a": "T+3", "term_b": "T+2", "reason": "결제 영업일 수 불일치"}
  ]
}

문서 A:
{doc_a_text}

문서 B:
{doc_b_text}
