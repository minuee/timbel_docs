# 감정 분류 기준 (5종)

어드바이저 감정 평가용 분류 체계. 단일 라벨 기준.

분류 : **화남**
정의 : 강한 분노 표출
판단 신호 : 욕설·비난·위협("가만 안 둬"), 책임자/상사 요구, 강한 반복·격앙, 인격 공격 
인접 분류와 경계 : 불만의 상위. **격앙도·공격성**이 임계값을 넘으면 화남 

분류 : **불만**
정의 : 부정적 평가·불편 표현 (차분~중간 강도)
판단 신호 : "왜 이렇게 오래 걸려요", "별로네요", "이게 맞아요?", 기대 미달·반복 불편
인접 분류와 경계 : 분노·공격성 없이 불만족만 표현하면 불만

분류 : **일반**
정의 : 뚜렷한 감정어 없는 사실·정보 교환   
판단 신호 : 감정어 부재, 정보성 발화
인접 분류와 경계 : **기본값(fallback)**. 애매하면 일반으로 

분류 : **만족**   
정의 : 응대·결과에 대한 긍정적 *평가*
판단 신호 : "잘 처리됐네요", "빠르네요", "좋아요", 칭찬
인접 분류와 경계 : 감사가 "고마움 표현"이라면 만족은 "좋다는 상태 평가"

분류 : **감사** 
정의 : 명시적 고마움 *표현*
판단 신호 : "감사합니다", "고맙습니다", "수고하셨어요"
인접 분류와 경계 : 종료 의례성 감사 주의 (아래 참고)


## 우선순위 규칙 (단일 라벨)

한 발화에 여러 감정이 겹칠 때 적용:

> **화남 > 불만 > 만족 > 감사 > 일반**

예) "덕분에 해결은 됐는데 너무 오래 걸려서 화났어요, 감사합니다" → **화남**

이탈·에스컬레이션 리스크가 큰 부정 감정을 우선 검출.


## 참고 — '감사' 과대검출 주의

한국어 상담 종료 시 의례적 "감사합니다"는 거의 모든 통화에 등장한다. 이를 전부 감사로 잡으면 라벨이 오염되므로:

- 종료 인사 구간의 의례적 감사는 **'일반'으로 처리**하거나
- 발화 위치(종료 구간)를 가중치로 두어 진심 감사와 구분한다.
