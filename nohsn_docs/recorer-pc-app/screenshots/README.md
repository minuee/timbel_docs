# 앱 화면 캡처 (2026-08-19)

기획 대조용으로 주요 화면을 캡처한 것입니다. macOS 14.6, Electron 38, 다크 테마 기준.

## 캡처 방법

실제 앱을 클릭해가며 찍은 것이 아니라, **Electron `webContents.capturePage()` 로 각 렌더러
페이지를 직접 렌더링해 저장**했습니다. 창 가림·마우스 커서·배경 노출이 없어 대조에 적합합니다.

재현:
```bash
export PATH="$HOME/.nvm/versions/node/v24.16.0/bin:$PATH"
./node_modules/.bin/electron <capture.js>     # 스크립트는 세션 스크래치패드에 있었음
```

## ⚠️ 읽을 때 주의

### `04-업로드진행팝업.png` 는 실제 모습이 아닙니다

"팝업이 열렸습니다 / 팝업 내용이 여기에 표시됩니다" 는 **하드코딩된 기본 placeholder** 입니다.
실제로는 메인 프로세스가 IPC 로 제목·부제·진행률을 주입합니다:

```js
createPopupWindow(mainWindow, {
  title: "파일 업로드 중",
  subtitle: "업로드가 완료될 때까지 기다려 주세요.",
  type: 'upload-progress', ...
})
```
그리고 `sendUploadProgressToPopup()` 이 퍼센트·전송속도·ETA 를 계속 갱신합니다.
캡처 시에는 메인 프로세스가 없어 기본값이 그대로 보인 것입니다.

### `05-업로드목록.png` 의 행은 더미 데이터입니다

"프로덕트 개선 회의 / 2025.07.29 11:30" 은 HTML 에 박힌 예시 행입니다.
실제로는 `jobs` 테이블에서 조회해 렌더링합니다.

### 그 외 화면

`01`, `02`, `03` 은 정적 UI 라 실제 모습과 동일합니다.

### 일본어 추가 시 손볼 곳

```
src/renderer/pages/summarizeWindow.html   radio name="language" 항목 추가 (ko/en/ch → ja)
```
`lang` 값은 업로드 시 `form.append('lang', ...)` 로 서버에 전달되고 `summaries.lang` 에도
저장되므로, **서버가 받는 코드값을 먼저 확인**해야 합니다 (`ch` 인지 `zh` 인지 등 기존 표기도 함께 점검).
