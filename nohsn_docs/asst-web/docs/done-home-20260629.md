## 2. 원본보기 하이라이트 — 코드 수정 (핵심 작업)

상담 STT → SSE `sources`(최대 3개 문서) → 문서 클릭 → 제목 우측 "원본보기" 아이콘 → 원본 모달.
모달에서 해당 청크(섹션)를 하이라이트하는 기능.

### 문제 ① 첫 번째(표/캡션형) 문서가 하이라이트 전혀 안 됨

**원인:** `focusByHeadingPath`가 `heading_path` 마지막 값 **전체**가 문서 요소에 포함돼야 매칭.
백엔드가 `"4. 투자실적 추이 — 연평균 수익률 (2025.08.31 기준, 단위: %)"`처럼 원문 제목에 없는 장식을 붙여줘서,
실제 DOCX 제목 `"4. 투자실적 추이"`와 매칭 실패 → 본문 폴백도 실패 → 강조 0.

**수정:** heading 후보를 **전체 → 구분자(`— – ( : ·`) 앞 토막** 순으로 매칭.
→ `"4. 투자실적 추이"`로도 잡힘. 전체 제목을 먼저 시도해서 기존 2·3번 정확도 유지.

### 문제 ② 제목 한 줄만 강조 → 제목 + 본문(섹션 전체)까지 넓게

**구현:** 청크 `content`(= 섹션 전체 텍스트)를 모달까지 전달.
제목 요소부터 다음 형제 블록을 순회하며 **텍스트가 content에 포함되는 동안** 계속 강조, 벗어나면 중단(=다음 섹션).

- 제목: 진한 노랑 `.kms-focus`
- 본문: 연한 노랑 `.kms-focus-range`  (색 바꾸려면 `#fff9c4` 한 줄)
- 표 대응: 렌더 표(셀 공백 없음) vs 마크다운 표(파이프→공백) 차이 무시 → **공백 제거 압축 비교**(`compactText`)
- 폭주 방지 `MAX_BLOCKS = 60`, `sectionContent` 없으면 **기존처럼 제목만 강조**(안전 폴백)
