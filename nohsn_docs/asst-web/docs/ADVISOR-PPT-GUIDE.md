# 어드바이저(Advisor) PPT 제작 가이드

> **이 문서의 목적**
> 고객사 제출용 제안서 중 **"AI 상담 어드바이저" 섹션(4장)** 을 PPT로 제작하기 위한 콘텐츠 가이드입니다.
> 본문은 **확정안**이므로 그대로 사용하고, 시각요소·레이아웃은 아래 지시를 참고해 구성하면 됩니다.

---

## 0. 제작 전 공통 지침

- **대상**: 고객사(콜센터 운영) 의사결정자 및 실무진
- **성격**: 전체 제안서 안에 들어가는 한 섹션. 어드바이저 제품에 한정한 4개 슬라이드.
- **톤**: 격식체, 간결. 과장된 마케팅 표현(최고, 혁신적, 압도적 등) 지양. 사실 기반으로 담백하게.
- **분량**: 슬라이드당 글머리표 4~6개 이내. 문장은 짧게.
- **용어 통일**:
  - 제품명: **AI 상담 어드바이저** (이하 "어드바이저")
  - VOC = 고객의 소리(Voice of Customer), 감정탐지 기능을 지칭
  - AHT = 평균 통화처리시간, ACW = 통화 후 후처리시간
- **수치 표기**: 효과 수치(%, 분)는 실측 전이므로 임의로 넣지 말 것. 정성적 표현으로 두거나 "(도입 후 측정)" 표기.

## 슬라이드 1 — 어드바이저 안내

**슬라이드 제목**: AI 상담 어드바이저

**부제(소제목)**: 상담사의 실시간 AI 파트너

**핵심 정의 문구 (상단 강조 배치)**:
> 통화 중에는 상담사를 실시간으로 지원하고, 통화 후에는 정리 업무를 자동으로 처리하는 AI 상담 보조 솔루션입니다.

**본문 — 3개 축으로 구성 (3단 카드 또는 3행 권장)**:

1. **상담 중 실시간 지원**
   - AI 지식 검색, 실시간 상담요약, 고객 감정(VOC) 탐지, 키워드·의도 감지

2. **상담 후 자동 정리**
   - 통화 요약, 후속 할일(To-do) 생성, 상담유형 자동 분류

3. **관리 및 코칭**
   - 다중 상담사 모니터링, 상담사별 성과 통계, 코칭 요청·추적

**하단 마무리 문구**:
> 별도 프로그램 전환 없이 상담 화면에 통합되어 제공됩니다.

**시각요소 지시**:
- 3축을 좌→우 흐름(상담 중 → 상담 후 → 관리)으로 배치하면 업무 타임라인이 직관적으로 전달됨.
- 아이콘: 검색/요약/감정/체크리스트/모니터 등 단순 라인 아이콘 권장.

## 슬라이드 2 — 주요 기능

**슬라이드 제목**: 주요 기능

**본문 — 표 형식 권장 (구분 / 기능 / 제공 가치)**:

| 구분 | 기능 | 제공 가치 |
|------|------|-----------|
| 상담 중 | AI 지식 검색 | 자연어 질의로 사내 정책·매뉴얼을 즉시 검색하고 답변을 생성 |
| 상담 중 | 실시간 상담요약 | 통화 내용을 자동으로 요약 |
| 상담 중 | 감정(VOC) 탐지 | 고객 감정(긍정/중립/부정)을 자동 표시해 불만을 조기 감지 |
| 상담 중 | 키워드·의도 감지 | 핵심 키워드와 문의 의도를 자동 추출 |
| 상담 후 | 자동 할일 생성 | 통화에서 도출된 후속 업무를 자동으로 할일(To-do)로 등록 |
| 상담 후 | 자동 상담분류 | 상담유형(대/중/소)을 자동으로 분류 |
| 관리 | 다중 모니터링 | 여러 상담사를 동시에 실시간으로 확인 |
| 관리 | 코칭 | 관리자가 상담사에게 코칭을 요청하고 확인 여부를 추적 |

**시각요소 지시**:
- 표가 길면 "상담 중 / 상담 후 / 관리" 3그룹으로 구분선 또는 색 헤더를 두어 가독성 확보.
- 기능 수가 많아 보이면 상담 중 기능을 메인으로, 상담 후·관리는 하단에 작게 배치.

## 슬라이드 3 — 시스템 아키텍처

**슬라이드 제목**: 시스템 아키텍처

> **주의**: 이 슬라이드는 **다이어그램(도식)이 중심**입니다. 아래는 도식에 곁들일 설명 캡션·글머리표입니다.

**설명 글머리표**:
- 상담사 화면(웹)은 백엔드 게이트웨이를 통한 호출만 수행하며, 화면단에서 외부 AI(LLM)를 직접 호출하지 않습니다. *(보안)*
- 요약·감정·분류·검색 등 AI 추론은 백엔드 AI 서비스가 전담하고, 화면은 그 결과만 표시합니다.
- 검색·답변 결과는 스트리밍(SSE) 방식으로 실시간 전달되어 응답을 빠르게 확인할 수 있습니다.
- 모든 호출은 토큰 기반 인증으로 보호됩니다.

**다이어그램 구성 요소(권장 흐름)**:
```
[상담사 웹 화면(Advisor)]
        │  (토큰 인증 호출 / 결과 표시)
        ▼
[백엔드 게이트웨이]
        │
        ▼
[AI 서비스]  ──  요약 / 감정(VOC) / 분류 / 지식검색
        │  (스트리밍 응답 SSE)
        ▼
[지식 데이터베이스 · 상담 데이터]
```

**시각요소 지시**:
- 좌측 "상담사 화면" → 우측 "AI 서비스" 단방향 흐름. 화면단에 LLM이 없음을 시각적으로 강조(보안 포인트).
- 스트리밍(SSE) 구간은 점선 화살표 등으로 실시간성을 표현.

## 슬라이드 4 — 주요 장점 / 도입 효과

**슬라이드 제목**: 주요 장점

**본문 — 4개 영역 (2x2 그리드 권장)**:

1. **상담 품질의 상향 평준화**
   - 신입 상담사도 AI 지식검색을 통해 정확한 안내 제공
   - 상담사 간 역량 편차 완화

2. **상담 생산성 향상**
   - 통화 1건에 대해 요약·할일·분류·감정이 한 번에 자동 생성되어 후처리시간(ACW) 절감
   - 자료 검색 시간 단축으로 평균 통화처리시간(AHT) 단축

3. **고객 만족 및 리스크 관리**
   - 감정(VOC) 탐지로 고객 불만을 조기에 감지하여 선제 대응

4. **관리 효율 제고**
   - 다중 모니터링·성과 통계·코칭을 통한 데이터 기반 상담사 관리

**하단 보조 문구(선택)**:
> 정량 효과(시간 절감률 등)는 도입 후 실측을 통해 산출됩니다.

**시각요소 지시**:
- 2x2 카드 그리드. 각 카드에 영역명 + 글머리표 1~2개.
- 효과를 강조하되 수치는 비워두고 "도입 후 측정" 문구로 신뢰성 유지.

## 부록 B — 작성 시 유의사항

- 감정(VOC) 탐지는 제품 기능으로 표기하되, 구체적 분류 정확도 수치는 명시하지 말 것.
- "실시간"이라는 표현은 상담 중 지원 기능(검색·요약·감정)에 한해 사용.
- 어드바이저 외 다른 제품/모듈 기능은 이 4장에 섞지 말 것(범위: 어드바이저 한정).
- 슬라이드 순서: 안내 → 주요 기능 → 시스템 아키텍처 → 주요 장점.
