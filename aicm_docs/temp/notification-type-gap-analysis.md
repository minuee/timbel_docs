## 2. 교차 검증 — 타 FD에서 알림이 명시되었으나 FD-NTF에 미등록된 시나리오

각 기능정의서에서 "알림 발송", "notification 소비자" 등이 명시적으로 기술된 시나리오 중, FD-NTF §1.1 테이블에 공식 등록되지 않은 것을 추출했다.
